## HTTP requests

The request builder takes a method, URL, params, headers and body. Body kinds: raw, JSON, XML, HTML, JavaScript, form-urlencoded, multipart and binary file. A raw request editor sits alongside.

## gRPC

Unary and server-streaming calls. Stop ends a stream. Client-streaming and bidirectional methods do not run. gRPC requests share collections, environments and variables with HTTP.

## Collections

A collection is a tree of requests and folders. Import and export use the Postman collection format. Export skips gRPC requests. Rename, duplicate, delete and move rows from the row menu. F2 renames. Drag moves a request or folder. **Move to collection** moves it to another collection. A move to another collection keeps request history.

Collections, environments and variables are files in `~/.kira-studio/api`. Use **Edit variables** or **Edit environment** to edit a file as a form or YAML, or **Open file** and **Reveal file** to use your editor. The order of `items` in a file is the order in the tree. A bad edit shows its line above the tree; the app keeps the last good version until the file is valid. `AGENTS.md` in that folder lists every option.

**Export collection…** does not write secret values to the file.

## Environments and variables

- Variables belong to a collection or an environment. Edit them in the variables dialog, in the file, or in your editor.
- **Duplicate** on an environment copies its file as `<name> copy`; the copy shares the secret values. **Delete** asks first and removes the file.
- A secret variable is written `secret: ${secret:<name>}`. Set its value under Environments, Secrets. The file never holds it.
- Environments carry a colour.
- Dynamic values come from Faker.
- The app masks secret values before it saves a response to history.

## curl

**Import from curl…** builds a request from a pasted command. **Copy as curl** copies any request out. Secret values stay hidden until you choose **Show secret values**.

## History and timeline

The app keeps the last 30 responses per request. The timeline shows DNS, connect, TLS, wait, response headers and download timings.

## Incognito tabs

Toggle incognito per tab. The app saves nothing from that tab: no response history, no call history, no tab state. An environment you pick there stays in memory.

## Defaults

`Settings > Api` holds the request defaults:

- HTTP version: 2.
- Request timeout: none.
- Maximum response size: 5 MB.
- SSL verification: on.
- Redirects: followed, up to 10.
- Cookie jar: disabled.
