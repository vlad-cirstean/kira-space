An agent on the Studio MCP server can send an HTTP request through your API environments. Each request waits for your approval unless you allow reads.

## Turn it on

API access is off by default. Open Settings, Studio MCP, API tools and choose the environments an agent may use.

Each environment sets how requests are approved. Reads can run without a prompt, and every other method asks first. You can also limit the hosts an agent may call.

An environment shares a variable with agents only when you allow it. A secret variable is shared only for the hosts you list.

## The approval card

<DocShot id="build-api-request" />

The card shows the method, the URL, the headers, the body and the environment. Secrets stay as `{{name}}` and show masked. Temporary variables are highlighted and listed above the request, one line each. Hover a name to see where it came from.

The **Sends** badge names every secret the request sends. Hover it to see each host and where the value comes from: an environment secret, a value you type, or a temporary secret.

A script on the request shows formatted. The text that runs is unchanged.

When several prompts wait, they group by agent session. **Deny all** answers only the prompts of that session.

## Values you type

<DocShot id="studio-api-values" />

An agent can name a value it needs, such as a one-time code. You type the value in the card. It goes only to the origin of that request. The agent never receives it.

A value you typed earlier stays available for a while. Open **Replace earlier values** to type a new one.

## Scripts

A request can carry a prepare script and a transform script. Prepare runs before the request. Transform runs on the response.

- `plain.name = value` sets a plain value. Later requests read it as `{{plain.name}}`.
- `secret.name = value` sets a secret. Later requests send it as `{{secret.name}}`.
- Scripts read plain values. They never read secrets.

## Response review

<DocShot id="build-api-review" />

You can hold a response for review before the agent gets it. The card shows the result, the script and the values it will set.

Choose **Send to AI** to release the result. Choose **Withhold** to keep it back. A script sets its values only after you send.

## Temporary variables

<DocShot id="studio-temp-variables" />

Temporary variables live in memory only. They are cleared when the app quits.

Each value expires after the retention you set. The range is 5 to 240 minutes, and the default is 60. The setting applies to new values only.

Clear one value, or clear all, in Settings, Studio MCP, Temporary variables.
