An agent records proof that its work does what the task asks. A proof is a folder `proofs/<slug>/` in the task folder: a `proof.md` file with ordered steps, plus any image and data files. A step is a table, a chart, a diagram, an image, a document or a list of key values. The agent writes the files; Kira picks them up from the folder. Kira accepts the whole folder or none of it, and shows it in the task. A proof shows behavior (data, responses, screenshots), not code. There is no proof tool.

A `proof.md` starts with `name` and `summary`, then `steps`. Each step has an `id`, a `description` and a `view`, and its data either inline or as a file in the folder. The task's `README.md` shows an example.

## Proof window

<DocShot id="build-proof-window" />

The window shows one proof, with its steps as tabs. The header shows the folder `proofs/<slug>` with buttons to open or reveal it and to delete the proof. A step shows its source, its query and its data exactly as the agent recorded them. Data renders as literal text, never as markup.

Open a proof from the task's Details list or from the prompt that appears when an agent adds one. The summary shows above the steps, and each step's explanation above its data. The camera button copies the active tab as a PNG. The menu beside it saves the tab, or every tab into a new folder, as JPEG files.

## Chart, diagram and image steps

<DocShot id="build-proof-chart" />

A chart step draws a line, bar, histogram, area, scatter or pie chart. A diagram step draws a Mermaid flowchart or sequence diagram from the recorded source.

<DocShot id="build-proof-diagram" />

An image step shows a PNG, JPEG, WebP or SVG file from the proof folder, such as a screenshot of the interface the agent checked. The window fits it to the width and scrolls a tall one. A GIF, an animated image or an SVG with scripts or outside references is refused, and the reply to `step.finish` says why.

## Edits wait for you

When an agent edits or deletes an accepted proof, it gives a reason and the change waits. Your own edits apply at once. The window shows **Current**, **Proposed** and **Compare**. A step tab and the change panel carry a badge: added, changed, removed or unchanged. Accept or reject the edit.

<DocShot id="build-proof-compare" />

## Proof in the task

The proof joins the task's Details tab, in one list with the handover notes. The list shows the newest first. A **Timeline** toggle in its header switches the view.
