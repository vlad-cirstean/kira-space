An agent records proof that its work does what the task asks. A proof session holds ordered steps. A step is a table, a chart, a diagram, an image, a document or a list of key values. The agent saves a session in one call with `proof_save`, which also shows it in the task.

## Proof window

<DocShot id="build-proof-window" />

The window lists sessions on the left and the steps of one session as tabs. A step shows its source, its query and its data exactly as the agent recorded them. Data renders as literal text, never as markup.

Open the window from **Window > Validation proof**, with or without a task. It shows the newest session. The camera button copies the active tab as a PNG. The menu beside it saves the tab, or every tab into a new folder, as JPEG files.

## Chart, diagram and image steps

<DocShot id="build-proof-chart" />

A chart step draws a line, bar, histogram, area, scatter or pie chart. A diagram step draws a Mermaid flowchart or sequence diagram from the recorded source.

<DocShot id="build-proof-diagram" />

An image step shows a JPEG, such as a screenshot of the interface the agent checked. The window fits it to the width and scrolls a tall one. The agent gives a file path or the file's bytes. The app stores a copy, so deleting the file later does not change the proof. Other image formats are refused.

## Edits wait for you

When an agent edits a closed session, the edit waits. The window shows **Current**, **Proposed** and **Compare**. A step tab and the change panel carry a badge: added, changed, removed or unchanged. Accept or reject the edit.

<DocShot id="build-proof-compare" />

## Proof in the task

The proof joins the task's Details tab, in one list with the handover notes. The list shows the newest first. A **Timeline** toggle in its header switches the view.
