# P606 plan: `dbmcp-script-long.spec.ts` ambiguous `run-stop` locator

Test-only fix. No app code changes.

## Cause (reproduced)

Two components render `data-testid="run-stop"` for a running run:

- `packages/workbench/src/automations/runs/ScriptRunView.vue:123`, inside `script-run-view` > `script-run-header`.
- `packages/workbench/src/automations/runs/RunsSection.vue:110`, inside `runs-section` > `run-row`
  (Automations panel, live runs only; `v-if="run.state === 'running'"`).

Spec test `contract: a long script run shows its output while it runs` feeds a `running` run through
`IPC.scriptRunsList`. Once `RunsSection` mounts beside the run tab, the unscoped
`page.locator('[data-testid="run-stop"]')` at line 58 matches both and `toBeVisible()` fails with a
Playwright strict-mode violation. Whether it fails depends on whether `RunsSection` has rendered its
row before the assertion resolves: a race.

Repro at chapter tip `c969898ea` (worktree `stream/p606`), after `bun run build:test`:

```
bunx playwright test --config=apps/kira-space/playwright.config.ts --project=ui \
  tests/ui/studio/dbmcp-script-long.spec.ts --repeat-each=20 --workers=4 --reporter=line
```

Result: 12 failed, 48 passed. All 12 failures are line 58. Decisive line:
`1) ... aka getByTestId('run-row').getByTestId('run-stop')  2) ... aka getByTestId('script-run-header').getByTestId('run-stop')`.

## Edits

File `apps/kira-space/tests/ui/studio/dbmcp-script-long.spec.ts` only.

1. Test 2 (line 53): add `const view = page.locator('[data-testid="script-run-view"]');` after
   `openRun`. Rewrite its assertions on that scope:
   - line 55-57: `await expect(view.locator('[data-testid="run-log"]')).toContainText('started');`
   - line 58: `await expect(view.locator('[data-testid="run-stop"]')).toBeVisible();`
   - line 59: `await expect(view.locator('[data-testid="script-run-result"]')).toHaveCount(0);`
2. Test 3 (line 62): same `view` constant. Rewrite:
   - line 67: `await expect(view.locator('[data-testid="run-outcome-exit"]')).toContainText('4');`
     (`RunOutcomeBlock` also renders in `TerminalTabView.vue` and `AdeAutomationsBlock.vue`.)
   - line 68: `await expect(view.locator('[data-testid="run-stop"]')).toHaveCount(0);`
     Unscoped, this count is 0 for any reason (also `RunsSection` hides ended runs); scoped, it
     asserts the run tab itself dropped Stop.

Optional tidy, same file: have `openRun` return `{ page, view }` instead of building `view` in each
test. Pick one form; do not do both.
