## F: `internal/homefold` (C1)

New package `internal/homefold/` (files `homefold.go`, `files.go`, `runs.go`, `copy.go`). It is the only
code allowed to name `KIRA_HOME` or `.kira-studio`.

API:

```go
var ErrStudioRunning = errors.New("homefold: Kira Studio is running")

type Options struct {
	Space     *sql.DB   // marker and runs target
	SpaceHome string
	Legacy    string    // "" folds nothing
	Studio    *sql.DB   // Runs only: <space>/studio.db, opened after Files
	Now       func() time.Time
	Rename    func(oldpath, newpath string) error // nil is os.Rename; flow test forces EXDEV
	Step      func(name string) error             // nil in production; flow test interrupts here
}

func LegacyHome() string
func Files(o Options) error
func Runs(o Options) error
func NeedsReregister(db *sql.DB) (bool, error)
func ClearReregister(db *sql.DB) error
```

Marker: Space `settings` key `homefold.p539`, JSON `{state, fresh, backup, scripts, collections,
runs, reregister}`; `scripts`/`collections`/`runs` are old-to-new id maps. States: absent, `moving`,
`files`, `runs`, `done`. Write helpers copy appmerge's `readMarker`/`writeMarker` shape (UPSERT). Each
step calls `o.Step(name)` first and returns its error unwrapped.

### F1 Files stage

1. Marker `done`, or `files`/`runs`: return nil.
2. Marker absent: if `Legacy == ""`, or the folder is missing, or it has no entries: write
   `{state: done, fresh: true}`; return.
3. Take the flock on `<legacy>/app.lock` (create if absent, as `AcquireLock` does). Busy: return
   `ErrStudioRunning`. Hold it until step 6 ends.
4. Marker absent: `backup = <space>/backups/p539-<ts>`; `MkdirAll` 0700. Move aside any pre-existing
   `<space>/studio.db` (+`-wal`, `-shm`), `<space>/connections`, `<space>/api` into the backup as
   `<name>.pre-p539` (none exist on real installs; covers dev leftovers). Write marker
   `{state: moving, backup}`.
5. Step `move`. `src = <backup>/kira-studio`.
   - Legacy exists, `src` missing: `o.Rename(legacy, src)`. On `EXDEV` (`errors.Is(err, syscall.EXDEV)`):
     `RemoveAll(src+".tmp")`, copy legacy to `src+".tmp"` (F3), verify (F3), rename tmp to `src`,
     `RemoveAll(legacy)`.
   - Legacy and `src` both exist (crash after tmp rename): verify, then `RemoveAll(legacy)`.
   - Legacy missing, `src` exists: continue.
6. Release the lock (its file moved with the folder).
7. Step `db`: if `src/kira.db` exists: open it (read-write, so SQLite replays its WAL; it is the backup
   copy), `RemoveAll(<space>/studio.db.tmp)`, `VACUUM INTO <space>/studio.db.tmp`, close, rename to
   `<space>/studio.db`. In state `moving` any `studio.db` is this stage's own output, so overwrite.
8. Step `dirs`: for `connections`, `api`: if `src/<name>` exists: `RemoveAll(<space>/<name>.p539tmp)`,
   copy (F3), `RemoveAll(<space>/<name>)`, rename tmp to `<space>/<name>`.
9. Step `tokens`: copy `mcp-db-token.json`, `mcp-db-header.token` with `renameio.WriteFile` mode 0600.
   `reregister = true` when `mcp-db-token.json` existed.
10. Step `prompts`: if `<backup>/space-llm-prompts.json` missing and `<space>/llm-prompts.json` exists,
    copy it there. Merge `src/llm-prompts.json` into the Space file: move `mergePrompts`, `readPrompts`,
    `promptsDoc` from `appmerge` here unchanged except the source path. Idempotent (adds missing ids only).
11. Log, once, every top-level `src` entry not handled (`logs`, `app.lock`, `automations-mcp`, `sandbox`,
    `sandbox-cache`, `mcp-header-helper.sh`, `kira.db-wal`, `kira.db-shm` at Info as "left in backup";
    any other name at Warn as "unknown, left in backup"). `runs/`, `automations/` belong to Runs.
12. Step `files-done`: marker `{state: files, reregister}`.

### F2 Runs stage

Runs after `studiostorage.Open` and `appmerge`.

1. Marker not `files`/`runs`: return nil.
2. Step `space-backup`: if `<backup>/space.db` missing: `RemoveAll(space.db.tmp)`, `VACUUM INTO
   <backup>/space.db.tmp`, rename.
3. Step `map` (state `files` only; state `runs` reuses the stored maps):
   - Studio script ids: `SELECT id FROM custom_scripts` in `o.Studio`, union stems of `src/runs/*.yaml`
     matching the regex. Taken: Space `custom_scripts` ids union stems of `<space>/runs/*.yaml`.
   - Map each Studio id: itself if free, else the suffix rule in Decisions. Add every new id to the taken
     set as it is assigned.
   - Collections: by name to the Space id; else own id; else new id.
   - Runs: own id; on collision with a Space `script_runs` id, `ids.NewID()`.
   - Write marker `{state: runs, scripts, collections, runs}` before any row or file write.
4. Step `rows`: one Space transaction, `INSERT OR IGNORE` throughout, values read from `o.Studio` first:
   - `custom_script_collections` rows not merged by name, mapped id, `sort_order` offset after Space max.
   - `custom_scripts`: mapped `id`, mapped `collection_id`, `sort_order` offset after Space max.
     Column list: read with `PRAGMA table_info(custom_scripts)` on both DBs and use the shared column set,
     so a column added later on one side cannot silently drop.
   - `script_runs`: mapped `id`, mapped `script_id`; `cwd` with prefix `<legacy>/automations/<old>`
     rewritten to `<space>/automations/<new>`. Legacy prefix: the path recorded in the marker at F1 (add
     field `legacy`).
   - `script_run_logs`: mapped `run_id`.
   - `secret_values` where `scope = secrets.ScopeScriptParam`: mapped `owner`, `value` verbatim.
   - If any copied script has `config_json = ''`: delete Space `settings` key `config.migrated.runs`, so
     `Loader.migrate` (`configfs.MigrateOnce`) exports it to a run file on boot.
5. Step `run-files`: for each `src/runs/<old>.yaml`: target `<space>/runs/<new>.yaml`; skip if present;
   else `renameio.WriteFile` with the source mode. Unmatched names in `src/runs/` stay in the backup
   (Warn).
6. Step `automations`: for each `src/automations/<old>/`: target `<space>/automations/<new>`; skip if
   present; else copy to `<target>.p539tmp` (F3), rename.
7. Step `studio-delete`: one Studio transaction deleting the copied rows (`script_run_logs`, `script_runs`,
   `custom_scripts`, `custom_script_collections`, `secret_values` scope `script-param`). Studio DB
   foreign keys: collections cascade to scripts; delete children first anyway.
8. Step `done`: marker `{state: done, ...}` (keep maps and `reregister`). `slog.Info` with backup path.

Running or restore-pending copied runs: Space `scriptruns.Service.Recover` handles them on boot as it does
its own rows.

### F3 Copy and verify

- Copy: `os.CopyFS(dst, os.DirFS(src))` if the toolchain's `os.CopyFS` copies symlinks (check
  `go doc os.CopyFS`); else a `filepath.WalkDir` copier for dirs, regular files and symlinks
  (`os.Readlink`/`os.Symlink`); named requirement: symlinks in user `automations/` dirs. Then a chmod pass
  restoring each source mode (CopyFS loosens modes; tokens must stay 0600).
- Verify: walk both trees; same relative paths and types, same sizes, same sha256 for regular files.
  Mismatch returns an error; the source stays.
