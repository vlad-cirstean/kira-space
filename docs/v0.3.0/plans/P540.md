## Decisions

- Subfolder name: `config`. Layout `<home>/config/<module>/`, one folder per module, name = the module's
  existing config-folder key (so `config_last_valid` rows and `ConfigFilesService` keys stay unchanged):
  `connections`, `api`, `runs`, `workflows`, `steps`, `repos`, `agent`, plus `prompts` (holds
  `llm-prompts.json`). Each module folder keeps its generated `AGENTS.md`. No top-level file in `config/`.
- In scope (audit): `connfiles` (connections), `apifiles` (api: collections, environments), `scripts.Loader`
  (runs), `adeflow.Reader` (workflows, incl. hidden `.p526-backup/` marker dir), `adeflow.StepLibrary`
  (steps), `repocfg` (repos), `agentctx` + `agentcfg` (agent: `context.md`, `settings.yaml`), `llmprompts`
  store (`llm-prompts.json`: user prompt overrides, no secrets; stays JSON, it is not a `configfs` module).
- Stays out of `config/` (secret, runtime or DB; nothing in `config/` needs `.gitignore`): `kira.db`,
  `studio.db` (+`-wal`/`-shm`), `review.db`, `agent-secrets.db`, `mcp-db-token.json`,
  `mcp-db-header.token`, `mcp-header-helper.sh` (regenerated, names the token path), `app.lock`, `logs/`,
  `backups/`, `agent-usage.json` (usage counters), `agent-context/` (launch snapshots), `ade/` (run MCP
  files, task dirs), `automations/` and `automations-mcp/` (script working dirs, runtime), `op-owners/`,
  `mobile/` (TLS material), sandbox dirs. Cipher key lives in the OS keychain, no file.
- Transient files inside `config/`: `configfs.WriteAtomic`/`renameio` temp files are hidden and renamed in
  place; `homefold`'s `<name>.p539tmp` copy dir becomes a sibling inside `config/` for the length of one
  copy. Neither needs ignoring.
- One resolver, root `internal/configfs/root.go`:

  ```go
  // RootName is the config subfolder of an app home; it can later be a git repo.
  const RootName = "config"

  // Root is <home>/config.
  func Root(home string) string { return filepath.Join(home, RootName) }

  // ModuleDir is <home>/config/<module>, the one config-root resolver.
  func ModuleDir(home, module string) string { return filepath.Join(Root(home), module) }
  ```

  Module names are package constants, never literals at call sites: `connfiles.Folder = "connections"`,
  `apifiles.Folder = "api"`, `scripts.Folder = "runs"`, `adeflow.WorkflowsFolder = "workflows"`,
  `adeflow.StepsFolder = "steps"` (export the existing `stepsFolder`), `repocfg.Folder` (exists),
  `agentctx.Folder` (exists), `llmprompts.Folder = "prompts"`, `llmprompts.File = "llm-prompts.json"`.
- Deleted joins/resolvers: `adeflow.Dir`, `adeflow.StepsDir`, `connfiles.Dir`, `apifiles.Dir`,
  `kirapaths.SharedAgentDir` (no caller left; the agent folder resolves through `ModuleDir`), and
  `kirapaths.SharedAgentSecrets` (no caller; `wireAgentSettings` joins `agent-secrets.db` itself).
- `config/` root exists before any watcher starts: `WatchDir` adds the folder's parent and fails if it is
  missing. `config.EnsureLayoutAt` creates `configfs.Root(home)` at 0700 after `kirapaths.EnsureLayoutAt`
  (main and `flowharness.build` both call it). `ipcfixture.NewApp` calls `config.EnsureLayout()` once.
- Watchers: each `configfs.Folder` watches its own `Dir`; only `Dir` changes. No own-write suppression exists
  in `configfs` (a save's own event reloads idempotently by hash); nothing to update.
- Shared-folder rule: `agentctx` and `agentcfg` both use `configfs.ModuleDir(home, agentctx.Folder)`.
- DB MCP / Claude registration: registration names only `<home>/mcp-header-helper.sh` and the token files,
  which stay at the home root. No prompt in `internal/llmprompts/registry.go` or `dbmcp` names a config
  folder path (grep `kira-space/` and folder names: none). No re-registration, no change there.
- No DB row stores a config path: projections key by folder name and file stem (migrations 0054-0056,
  0064; `config_last_valid` keys). Only the files move.
- Boot order: configfold runs right after `storage.Open`/`repos.New`, before `homefold.Files`. Then
  `homefold` writes Studio data straight into the new layout through the resolver, and `homefold.Runs`
  reads/writes run files in `config/runs`. P539 and P540 ship in one release, so no user ever has a
  P539-only layout; dev homes that ran P539 builds are handled because `<space>/connections`, `<space>/api`
  are ordinary legacy entries for configfold.
- Argv shims (`memory-mcp`, memory CLI in `wire.go:67,69`) run before the migration but read the prompts
  path from the resolver; the app launches them after its own boot, so the file is already moved. A CLI call
  before the first P540 launch sees no overrides (defaults), never an error.
- Startup failure: configfold errors go to `reporter.Fatal(startupfail.StepStorage, err)` (homefold
  precedent). The marker keeps its last state; next launch resumes.

## C3: `internal/configfold`

Files `configfold.go`, `move.go`. API:

```go
type Options struct {
	Space  *sql.DB // marker
	Home   string  // the Space home
	Now    func() time.Time
	Rename func(oldpath, newpath string) error // nil is os.Rename; flow test forces EXDEV
	Step   func(name string) error             // nil in production; flow test interrupts here
}

func Run(o Options) error
```

Entries (legacy name at `<home>/<name>` to target): `connfiles.Folder`, `apifiles.Folder`, `scripts.Folder`,
`adeflow.WorkflowsFolder`, `adeflow.StepsFolder`, `repocfg.Folder`, `agentctx.Folder` to
`configfs.ModuleDir(home, name)`; file `llmprompts.File` to `configfs.ModuleDir(home, llmprompts.Folder)/
llmprompts.File`. One ordered slice `entries` in `configfold.go`; `appwire` builds the `ConfigFilesService`
map from the same folder constants (C4).

Marker: Space `settings` key `configfold.p540`, JSON `{state, fresh, backup}`, UPSERT like
`homefold.writeMarker`. States: absent, `moving`, `done`. Each step calls `o.Step(name)` first and returns its
error unwrapped. Step names: `backup/<name>`, `move/<name>`, `done`.

1. Marker `done`: return nil.
2. Marker absent: if no legacy entry exists (`fsmove.Exists` via `os.Lstat`, so a dangling symlink counts),
   write `{state: done, fresh: true}`; return.
3. Marker absent: `backup = <home>/backups/p540-<UTC 20060102T150405Z>`. Write marker
   `{state: moving, backup}` first, then `MkdirAll(backup, 0700)`.
4. For each entry, step `backup/<name>`: skip if legacy missing or `<backup>/<name>` exists. Else
   `RemoveAll(<backup>/<name>.tmp)`, `fsmove.CopyTree` (dirs, files, symlinks kept as links, modes kept),
   `fsmove.VerifyTree`, rename tmp to `<backup>/<name>`. A legacy path that is itself a symlink is backed up
   as the link.
5. `MkdirAll(configfs.Root(home), 0700)`; `MkdirAll` the `prompts` folder 0700 before the file move.
6. For each entry, step `move/<name>`. `src = <home>/<name>`, `dst` = target:
   - `src` missing: nothing.
   - `dst` missing: `o.rename(src, dst)`. On `EXDEV` (`errors.Is(err, syscall.EXDEV)`): `RemoveAll(dst+".tmp")`,
     `CopyTree` to `dst+".tmp"`, `VerifyTree`, rename tmp to `dst`, `RemoveAll(src)`. A symlink `src` moves as
     the link.
   - both exist (manual or dev leftover; crash cannot cause it, rename is atomic): `dst` wins. For a dir: each
     top-level child of `src` that `dst` lacks is renamed in; a child both have stays only in the backup and is
     logged once at Warn with both paths. Then `RemoveAll(src)`. For the prompts file or a symlink `src`: keep
     `dst`, Warn, `os.Remove(src)`. Every sub-step is safe to repeat.
7. Step `done`: marker `{state: done, backup}`; `slog.Info("config fold done", "scope", "startup",
   "backup", backup)`.

Retention: backup kept until the user deletes it (PACKAGING, site install page). Restore: app closed, move
`<backup>/<name>` back and delete `config/<name>` and the marker row (documented in ARCHITECTURE only).
