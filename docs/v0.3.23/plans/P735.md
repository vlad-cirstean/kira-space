## Decisions

1. Sends (API prompt card only; no other card has the lines). One "Sends: {names}" fact listing every secret the
   request sends: environment credentials, typed inputs (needed or stored) and `{{secret.x}}` temporary
   secrets (`p.kept` with `secret`), deduped by name, order credential, input, temporary. Tooltip: one line per
   name, one key `studio.dbMcp.approval.api.sendsTo.label` "{name} to {hosts} ({source})", `source` from
   `…api.source.environment.label` "environment secret", `…api.source.typed.label` "you type it", `…api.source.
   temporary.label` "temporary secret". A stored input reads "temporary secret". Hosts: credential `hosts`,
   input `origin` without scheme, temporary secret the request host `p.host` (`KeptUse` carries no origin,
   `shared/domain/kept.ts:52-60`; the backend already refuses one sent elsewhere, `agentapi/kept.go:535`). Delete keys
   `…api.credential.label` and `…api.input.label`. "Uses:" stays distinct: temporary variables read (plain and
   secret), its tooltip "{name}, set by {request}". Overlap for a temporary secret is intended: Uses says
   where it came from, Sends says where it goes.
2. Shared row `frontend/src/studio/kept/TempVarRow.vue`, one line, `flex min-h-control items-center gap-1.5`:
   name (`KeptNameMark` without type, `font-data`, the request's mark class; `line-through` when deleted) as a
   `Tooltip` trigger (`@theme/components/ui/tooltip`, `tabindex="0"`); kind `Badge` "Plain"/"Secret" (existing
   variants and testids `kept-kind-plain|secret`); value `flex-1 min-w-0`; time left `shrink-0 tabular-nums
   text-muted-foreground text-kira-sm` (testid `kept-expiry`, omitted for staged); `#actions` slot. Props:
   `name`, `secret`, `deleted?`, `entry` (value fields), `expiresAt?`, `details: string[]` (tooltip lines),
   `staged?`, `stagedReveal?`. Tooltip lines, in order, empty ones skipped: "Set by {request}" or "Typed by
   you"; the agent session (`source.client`); Settings only "Goes only to {origin}" (`KeptEntry.origin`); "Set {relative}" (`useRelativeTime`
   from `@workbench/behaviour/format`); "Expires at {time}"; card only "Used in {sites}"; type ("List of 12",
   "Text"). No byte sizes anywhere: `keptTypeLabel` string case returns "Text" (`studio.kept.type.string.
   status` loses `{size}`; `bytes` drops from `TypedEntry`).
3. `KeptValueView.vue` becomes one line: plain = `TruncatedText` (`font-data`) of the first line of the
   preview, JSON objects/arrays compacted with `JSON.stringify(JSON.parse(..))` when not cut, `…` when cut;
   Copy keeps copying the whole value (`valueText`). Secret = `MaskedValue` (4 dots) or the revealed text
   (truncated, tooltip), then Reveal and, once revealed, Copy (rules unchanged). "Show all" stays only for a
   cut, stored value: an icon `TooltipIconButton` (`ICON.expand` or the nearest existing icon) in the actions
   that toggles a `FlushEditor` row under the line (`useKeptValue`, as today). Testids `kept-value-*` kept.
4. Card box: `KeptVariablesPanel.vue` heading `studio.kept.panel.title.label` "Temporary variables" (one key
   for request and query: delete `…panel.query.label` and the `title` prop), "Manage" link unchanged in place.
   List `flex flex-col gap-0.5`, rows `TempVarRow` with the × in `#actions` (`studio.kept.clear.tooltip`).
   `KeptVariableRow.vue` is deleted. Review box `StagedKeepList.vue`: heading "Will set", rows `TempVarRow`

   (`studio.kept.willKeep.deleted.status`). `UserInputsPanel.vue`: "Available for {minutes} min", replace box
