## 2. Token decision

New dedicated tokens, `--kira-on`/`--kira-on-fg` deleted (not re-pointed). Reason: M2 needs six
distinct values (on fill, on edge, mark, off edge, off knob, progress) where the old pair had two; the
progress fill now differs from the toggle fill; and §1 shows the four primitives are the family's only
consumers, so keeping `--kira-on` would leave a dead token. Literal hexes (no existing token holds
these values). All six are neutral greys (channel spread at most 8), so N18 still passes.

| token (`tokens.css`) | value | Tailwind (`tailwind-core.css`) | role |
| --- | --- | --- | --- |
| `--kira-toggle-on` | `#33333a` | `--color-toggle-on` | on fill: switch track, checkbox, radio |
| `--kira-toggle-on-edge` | `#c4c4cc` | `--color-toggle-on-edge` | on border |
| `--kira-toggle-mark` | `#f4f4f5` | `--color-toggle-mark` | check, dash, radio dot, on knob |
| `--kira-toggle-off-edge` | `#3e3e45` | `--color-toggle-off-edge` | off border (switch, checkbox, radio) |
| `--kira-toggle-knob` | `#6b6b73` | `--color-toggle-knob` | off switch knob |
| `--kira-progress-fill` | `#b4b4bc` | `--color-progress-fill` | progress indicator |

Off fill stays `bg-field` (`--kira-bg-input` #27272c), as today.

Contrast (WCAG relative luminance, computed):

- mark #f4f4f5 on on-fill #33333a: 11.4:1. On edge #c4c4cc on field #27272c: 8.6:1; on bg 9.9:1.
- on-fill vs off field: 1.19:1. On/off reads from the light edge and bright mark, as in mock.
- off edge #3e3e45 on field: 1.4:1; on bg #1b1b1e 1.6:1. Below the old 3:1 non-text bar
  (`tokens.css:21` comment, ARCHITECTURE:69). User's explicit choice; the off control still reads by
  its field fill plus knob #6b6b73 (2.8:1 on field). ARCHITECTURE drops the 3:1 claim for toggles.
- progress #b4b4bc on track (`#71717a` at 50% over ground, about #46464c on bg): about 4.3:1.

Focus. Global ring (`tailwind-core.css:208-224`): 1px `--kira-focus` #a1a1aa at offset -1px, drawn
over the element's own 1px edge. On a checked control it replaces the #c4c4cc edge: #a1a1aa vs
#c4c4cc is 1.48:1, so checked+focused is barely distinguishable from checked. Fix: add
`focus-visible:outline-offset-2` to Switch, Checkbox and RadioGroupItem roots. Ring then sits 2px
outside the control on the ground (#a1a1aa on bg 7:1, on field 5.8:1), clear of both on and off
edges. Focus token itself untouched. Precedent: SwatchPicker already uses `outline-offset-2`.
