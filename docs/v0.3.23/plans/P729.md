## 2. Variables tab

Files: `apps/kira-space/frontend/src/studio/api/VariablesMatrix.vue` (501 lines), `VariableCell.vue`,
`VariablesView.vue` (308 lines).

Root cause: `<Table columns class="min-w-max">` on top of theme `w-full` gives auto layout;
`min-w-44` on `<th>` is unreliable (ignored in WebKit auto layout), and truncating cells shrink to
nothing as environments grow. Name column scrolls away with the rest.

Fix:

- `table-fixed` plus `<colgroup>`: Name `<col class="w-56">`, one `<col>` per `columns` entry
  (shares remaining width), menu `<col class="w-10">`.
- Table `:style="{ minWidth: `calc(14rem + ${columns.length} * 11rem + 2.5rem)` }"` keeps `w-full`:
  each env column at least 11rem (176px, current `min-w-44` intent), grows to fill when few. Drop
  `min-w-max`. Constant `ENV_COL_MIN_REM = 11` in component.
- Scroll container `data-testid="variables-matrix-scroll"` already `overflow-auto`: whole grid
  (header included, since `TableHeader` is `sticky top-0`) scrolls horizontally.
- Pin Name: Name `<TableHead>` and body Name `<TableCell>` get `sticky left-0`. Head z above
  header row and body (`z-2`), body `z-1`. Opaque backgrounds: head `bg-elevated`, body
  `bg-background` plus `group-hover:bg-field` matching `tableRowClass` hover (row needs `group`
  class; check `TableRow` passthrough). New-row input cell same treatment.
- Divider: `border-collapse` drops sticky cell borders on scroll. Draw right divider with
  `shadow-[inset_-1px_0_0_var(--color-border)]` (use theme border token name from
  `packages/theme`), not `border-r`.
- Narrow (`NARROW_PX=760`, `VariablesView.vue:36-47`): `columns` holds one owner, min width formula
  yields under container width, layout unchanged. Keep `api-variables-matrix.spec.ts:273` green.
- Footer plural: `packages/theme/src/i18n/en.json` `studio.api.variables.footer.missing.status`
  becomes `"{count} value missing | {count} values missing"` (`t()` picks branch by `count`,
  `packages/theme/src/i18n/index.ts:39`; `scripts/copy/catalogRules.ts` accepts `|`). Call site
  `VariablesView.vue:299` already passes `{ count }`. Same bug in `footer.counts.status`
  (`"{variables} variables, {environments} environments"`): split into
  `footer.counts.variables` (`"{count} variable | {count} variables"`) and
  `footer.counts.environments` (`"{count} environment | {count} environments"`), joined in
  template; delete old key. Other locale catalogs, if any, get same keys.
