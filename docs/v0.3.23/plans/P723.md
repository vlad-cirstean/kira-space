## Result notes for SPEC

- `workflow_run` workflows execute from the default branch, so the removal takes effect only once
  this chapter's PR merges to `main`. Until then the old workflow still reruns failed PR runs, this
  chapter's included.
- Pushing a commit that touches `.github/workflows/` needs a token with the `workflow` scope
  (`PACKAGING.md` §7, P19 note). v0.3.20 to v0.3.22 changed workflows from this setup, so none is
  expected; a refused push is reported, never worked around.
