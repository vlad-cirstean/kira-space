## Goal

follows. Resulting order:

- Memory on: Agents (`ade`), Runs (`automations`), Memory (`memory`), Studio (`studio`), API
  (`api`), Docker (`docker`), Kubernetes (`kubernetes`), Git (`git`).
- Memory off (default): same minus Memory.

## Decisions

- Default stays Git. Default is an id (`WindowModes.Default`, `createModeStore` default, memory
  gate fallback), not "first tab". Spec asks for position only; changing where new windows open is
  a separate behaviour change nobody asked for. Persisted windows keep their mode.
- No shortcut work: no per-module chord exists. Result states that.
- No Go edit: `WindowModes.Valid` is a membership list.
