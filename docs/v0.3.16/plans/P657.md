## Design

### Root tracking: `internal/procroots` replaces `internal/agentproc`

One concern (Kira-launched process roots by group), two groups. No parallel copy of agentproc.

```go
// Package procroots records the root pid of every live process tree this process launched, by
// group. Process-wide by nature (pids are); internal/metrics reads it.
package procroots

// Set is one group's ref-counted root pids.
type Set struct { mu sync.Mutex; roots map[int32]int }

var (
	Agents  = &Set{roots: map[int32]int{}} // agent CLI trees
	Scripts = &Set{roots: map[int32]int{}} // user script trees: script runs, pre-connect scripts
)

func (s *Set) Track(pid int) (untrack func()) // body = agentproc.Track, on s
func (s *Set) Roots() []int32                 // body = agentproc.Roots, on s
```

Keep agentproc's pid-reuse note in the package doc. Method values keep call sites one-token swaps:
`procroots.Agents.Track` fits `RunIOTracked`'s `func(int) func()`, `procroots.Agents.Roots` fits
`func() []int32`. Delete `internal/agentproc/`.

### Classification precedence

Agents > Scripts > App. `groupProcesses` walks agent roots first (unchanged), then script roots,
skipping any pid already claimed as agent (a script root inside an agent tree, or an agent root
inside a script tree, stays Agents). App anchor/helper matching skips both groups. A pid is in at
most one group.

### Lifetimes

- Terminal: tracked from `Registry.Open` registration until `sess.unregister` (same as agent
  sessions).
- Headless: tracked from successful `cmd.Start()` until `cmd.Wait()` returns.
- Pre-connect: tracked from `cmd.Start()` until the leader's `cmd.Wait()` returns (spawn's wait
  goroutine). A one-shot's background child reparents to init after the leader exits and drops out of
  the tree, the same rule Agents follow ("Descendants reparented … drop out").
