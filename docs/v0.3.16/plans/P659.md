## Design

### 1+2. Hover clusters move to the right action zone

Card head, line 1 becomes
`[title flex-1] [hover cluster] [status menu] [action button]`:

- `AdeTaskCard.vue`: title wrapper `<span class="flex min-w-0 items-center">` gets `flex-1`; delete
  the separate `<span class="flex-1" />` spacer (line 208). Hover cluster span moves after the
  title wrapper unchanged in position order but now sits right-aligned next to the status menu.
  Keep its visibility classes as is (`hidden ... group-hover/head:flex group-focus-visible/head:flex
  group-has-[:focus-visible]/head:flex has-[[data-state=open]]:flex has-[[data-pinned]]:flex`).
  Status menu and action button stay right-anchored; on hover only the title truncates more.
- Cluster gets `data-testid="ade-card-actions"` (spec hook for the alignment assertion).

Branch row, board layout:

- `AdeBranchRow.vue`: move the hover-cluster `<span class="hidden shrink-0 ...">` (line 497-546)
  out of column 2 into column 3 (`<div class="flex items-center gap-1">`, line 559), as its first
  child, before `AdeOpStatus`. Column 2 then reads `[name block] [context flex-1]`; the `v-else`
  spacer stays.
- Cluster gets `data-testid="ade-branch-actions"`.
- Pencil: `AdeTaskBranchMenu align="start"` becomes `align="end"` (it now sits at the right edge,
  its dropdown and Change-branch popover open leftward under it).
- Idle rows are pixel-identical to today: column 3 is `auto` and the cluster is `hidden` until
  hover or focus. On hover column 3 widens; column 2 (`minmax(0,1fr)`) shrinks, context first
  (`flex-1 basis-0`), name keeps its left edge.

Result: every hover button on a card sits right, in the same zone as status, action, state glyphs
and danger actions. Nothing appears against the title or branch name.

### 3. Remove the More buttons on the list

- `AdeTaskCard.vue`: delete the `ade-card-more` `TooltipIconButton` (line 200-206). Right-click and
  Shift+F10 (`useShortcut(head, ['menu.open'], ...)`, already present) stay the paths to the task
  menu.
- `AdeBranchRow.vue` board layout: delete the `ade-branch-more` `MenuIconButton` (line 523-531).
  Panel layout (task panel grid, line 391-399) keeps its More: the feedback is about list cards,
  and the panel row actions column is a separate surface. `MenuIconButton` import stays (panel).
- Keyboard path for a board row, which had only the More button: add
  `useShortcut(rowRef, ['menu.open'], (_id, ev) => onMenuKey(ev))` in `AdeBranchRow.vue`, where
  `onMenuKey` returns early for `panel`; for `taskRow` it emits `taskMenu` with a synthetic anchor
  (call the parent with the row element: change the emit to `taskMenu: [ev: MouseEvent | HTMLElement]`
  and in `AdeTaskCard.vue` handle an element with `taskMenu.openAt(el)`, a MouseEvent with
  `taskMenu.open(ev)`); otherwise `contextMenu.openContextMenuFor(rowRef.value, menuItems())`
  (`packages/workbench/src/state/contextMenu.ts` line 77). Same items as right-click; no new menu
  code.

### 5. Agent indicator bigger

Card head lead becomes a left column spanning both head lines:

- `AdeTaskCard.vue` head (line 123-281): head `div` changes from
  `flex-col justify-center gap-0.5` to `flex-row items-center gap-1.5`. Children: lead
  `<span class="inline-flex w-6 shrink-0 justify-center" data-testid="ade-row-lead">`
  (moved out of line 1), then `<div class="flex min-w-0 flex-1 flex-col justify-center gap-0.5">`
  wrapping line 1 and line 2. Line 2 drops `pl-6`. Head height stays `h-board-row` (44px).
- `plan/AdeTaskSessions.vue`: new prop `size?: 'md' | 'lg'` (default `'md'`, today's look, used by
  `later/AdeShelfRow.vue` single-line row, unchanged). `lg`: button
  `h-6 min-w-6 rounded-full px-1 gap-0.5`, `AdeActivityIcon :size="16"`, finished check
  `CodiconIcon :size="16"`, running count `text-kira-md`. Pick classes via a computed
  `const SIZE = { md: {...}, lg: {...} } as const` map, Tailwind only.
- `AdeActivityIcon.vue`: size union `12 | 14 | 16`; `BADGE[16] = 'size-4'`, `DOT[16] = 'size-3'`.
  Additive; existing callers unchanged.
- `AdeTaskCard.vue` passes `size="lg"`.

Branch-row sparkle (`ade-branch-agent`, branch origin) is not the agent indicator and stays
13px. The `ade-row-lead` empty slot stays for tasks without sessions so titles line up.
