## Files and grouping

Cut each file at the opening marker of its first chapter; a file runs to the line before the next file's first
marker, so blank separator lines and the "Fixes outside chapters" section stay where they are. Lines 1-6 (preamble
plus blank) are the part replaced by the index; files hold lines 7-7827 byte for byte, no added headers.

Why:

- Six files of 1,086 to 1,540 lines. v1.9 and v2.0 are each about 1,300 lines alone, so they stand alone; the
  rest group by version line (v1 early, v1 late, v2 after v2.0, the v0.x renumbering).
- Name = two-digit order prefix plus first chapter. The prefix gives `cat docs/history/*.md` and "newest" a
  defined order despite the non-monotonic names. First chapter never changes, so no file is ever renamed when a
  close appends; the range lives only in the index.
- Newest file is the highest prefix (`06-v0.2.10.md`), also the last index entry. Every close appends there. No
  size cap (user decision): a new file (`07-<first chapter>.md`) starts only when the user asks; then the previous
  last index entry gets its end chapter and a new entry is added.

## scripts/docshistory today

- `main.go` `run`: chdir to repo root, flags (`--history` default `docs/HISTORY.md`, `--runs docs/history-runs`),
  `checkChapter` (`^v\d+(?:\.\d+)?$`, so every v0.x chapter is refused), dispatch: `units`, `distill`, `verify`
  read chapter sources and run records only; `render` and `fold` (distill, render, verify) touch the history file;
  `repoint` rewrites other files.
- `render.go` `readBlocks(path)`: one regex over the whole file, `map[ch]body`; close-marker name not checked
  against the open name. `writeBlocks(path, blocks)`: rewrites the whole file as `preamble` const plus every block
  sorted by `versionKey`. So today it drops "Fixes outside chapters" and would sort `v0.2.x` before `v1`.
  `cmdRender`: per chapter, render from `docs/history-runs/<ch>.jsonl`; no runs and a block present: skip; no runs
  and no block: error; then `writeBlocks`, print sizes.
- `repoint.go`: rewrites `docs/<ch>/...` references across `git ls-files` to the citation form
  `docs/HISTORY.md (<ch>)` / `(<ch> <id>)`, or `git show <commit>:...` in operative files. `skipRepoint` skips
  `docs/v*`, `docs/HISTORY.md`, workflows, pending changes, itself, two testdata roots. Never reads blocks.
- `standing.go` (`doc` subcommands for ARCHITECTURE/PACKAGING) and `verify.go`: no history-file access.
- Tests: `parse_test.go` `TestBlocksIdempotent` (writeBlocks/readBlocks round trip), `TestRepointText`
  (includes a `skipRepoint` table). `standing_test.go` unaffected.

## scripts/docshistory changes (minimal)

Goal: works over `docs/history/`, re-renders only blocks that already exist, never adds a chapter (not a close
mechanism; CLAUDE.md forbids it for the close).

1. `render.go`:
   - Drop `preamble` const and `writeBlocks` (text now lives in the hand-written index).
   - `type histBlock struct{ file, body string }`.
   - `chapterBlockRe` captures the close name too: `(?s)<!-- chapter (\S+) -->\n(.*?)<!-- /chapter (\S+) -->\n`.
   - `readBlocks(dir) (map[string]histBlock, error)`: `filepath.Glob(dir/*.md)` (sorted); error on open/close name
     mismatch and on a chapter found twice (name both files).
   - `spliceBlock(path, ch, body string) error`: per-chapter regex with `regexp.QuoteMeta(ch)` on both markers,
     `FindStringSubmatchIndex`, write `text[:m[2]] + body + text[m[3]:]`. String concat, not `ReplaceAllString`
     (bodies may hold `$`). Every byte outside that body unchanged.
   - `requireBlocks(dir, chapters) (map[string]histBlock, error)`: `readBlocks`, then error for each missing
     chapter: `<ch>: no block in <dir>; a new chapter is closed by hand (CLAUDE.md "Closing a chapter")`.
   - `cmdRender(runs, dir, chapters)`: `requireBlocks` first (all checked before any write); per chapter: no runs,
     skip; else render and `spliceBlock(b.file, ch, body)`; print `<ch> <file> <bytes> bytes, <lines> lines`.
     Drop the `sort` import if unused.
2. `main.go`: package comment "re-renders folded chapter blocks in docs/history/"; usage `render` line "rewrite
   the chapters' existing blocks in docs/history/ (a chapter with no block is refused)"; `--history` default
   `docs/history`, help "history directory"; `fold` calls `requireBlocks(*history, chapters)` before
   `runDistill` so a missing block fails before tokens are spent.
3. `repoint.go` `skipRepoint`: add `strings.HasPrefix(path, "docs/history/")` (history files quote old
   `docs/<ch>/` paths, same reason `docs/HISTORY.md` is skipped). Keep `docs/HISTORY.md` in the list (index).
   Citation form `docs/HISTORY.md (<ch>)` unchanged: the index resolves it.
4. Not changed: `checkChapter` regex, `versionKey` ordering. Widening them would only serve adding v0.x chapters,
   which is the close's job.

Tests (existing file, no new test file):

- Replace `TestBlocksIdempotent` with `TestBlocksSplice`: temp dir, file `a.md` with blocks v1 and v1.1 and a
  `## Fixes` paragraph between, file `b.md` with v1.9. Assert `readBlocks` maps each chapter to its file and body;
