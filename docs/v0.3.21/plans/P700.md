## Design

### Package

`internal/fileservice` (module-root `internal/`: `configfs`, `scripts`, `agentport`, `agentmcp`, `agentcfg`,
`agentctx`, `llmprompts`, `scriptruns` live there and must import it). Imports stdlib, `renameio/v2`,
`internal/fswatch` only. No app imports.

Files:

| File | Content |
|------|---------|
| `fileservice.go` | `Service`, `Policy`, `New`, `Host`, `Info`, `Entry`, `Version`, sentinels, doc comment with the rules below |
| `path.go` | name checks, Contain rule (pathsafe algorithm moved verbatim), Refuse rule (taskfiles `lstat` walk moved), `Path` |
| `read.go` | `Stat`, `Exists`, `Read`, `Open` |
| `write.go` | `Write`, `Create`/`Pending`, `TempFile`, `TempDir`, `Mkdir`, `MkdirAll`, `Chtimes`, dir fsync |
| `remove.go` | `Remove`, `RemoveAll`, `Rename` |
| `list.go` | `ReadDir`, `Walk` (taskfiles lister caps moved), `Glob` |
| `copy.go` | `Copy` (fsmove `CopyVerified` + `CopyTree` + `VerifyTree` moved), `Hash` |
| `watch.go` | `Watch`, aliases `Event`, `Op`, op consts, `Watcher`, `Unlimited`, `Debouncer`, `NewDebouncer` |
| `flags_unix.go` / `flags_other.go` | `openFlags`, `linkCount` (moved from taskfiles/store) |

### API

```go
type SymlinkRule uint8
const (
	Contain SymlinkRule = iota // a symlink may resolve only inside Root (host-wide: followed)
	Refuse                     // any symlink component is ErrUnsafe; leaf opened O_NOFOLLOW
)

type Policy struct {
	Root      string      // "" = host-wide: names are absolute; else names are clean relative slash paths under Root
	Symlinks  SymlinkRule
	PlainOnly bool        // refuse hard-linked (nlink > 1) and special files (task files)
	Private   bool        // new files 0600, dirs 0700; default 0644 / 0755
	MaxRead   int64       // Read cap when the call passes 0; 0 = DefaultMaxRead (64 MiB)
}

func New(p Policy) (*Service, error) // rooted: MkdirAll(Root), EvalSymlinks once (NewLocal's rule)
func Host() *Service                 // shared host-wide Service, Policy{}

func (s *Service) Root() string
func (s *Service) Path(name string) (string, error)            // checked absolute path for argv, editor, git
func (s *Service) Stat(name string) (Info, error)              // Lstat under Refuse
func (s *Service) Exists(name string) (bool, error)            // dangling link counts (fsmove.Exists rule)
func (s *Service) Read(name string, max int64) ([]byte, Info, error)
func (s *Service) Open(name string) (*os.File, Info, error)    // read-only stream (request bodies, uploads, search)
func (s *Service) Write(name string, data []byte, o WriteOptions) (Info, error)
func (s *Service) Create(name string, o WriteOptions) (*Pending, error) // streamed atomic write
func (s *Service) TempFile(dir, pattern string, data []byte) (path string, cleanup func(), err error) // 0600
func (s *Service) TempDir(dir, pattern string) (path string, cleanup func(), err error)              // 0700
func (s *Service) Mkdir(name string) error                     // ErrExist when present
func (s *Service) MkdirAll(name string) error
func (s *Service) Remove(name string) error                    // file or empty dir; missing = nil
func (s *Service) RemoveAll(name string) error                 // refuses the root itself
func (s *Service) Rename(from, to string, o RenameOptions) error
func (s *Service) Copy(from string, dst *Service, to string) error // verified tree copy through to+".tmp"
func (s *Service) ReadDir(name string) ([]Entry, error)        // sorted
func (s *Service) Walk(name string, o WalkOptions, fn func(Entry) error) error
func (s *Service) Glob(pattern string) ([]string, error)
func (s *Service) Hash(name string) (string, error)            // sha256 hex, streamed
func (s *Service) Chtimes(name string, t time.Time) error
func (s *Service) Watch(o WatchOptions) (*Watcher, error)

type WriteOptions struct {
	Perm      fs.FileMode // 0 = policy default
	KeepPerm  bool        // existing file's mode (codeworkspace, collections)
	Static    bool        // Perm ignores umask and re-tightens a looser file (mcpauth, Private)
	IfVersion *Version    // nil unconditional; "" must be absent; else must equal current
}
type RenameOptions struct{ NoReplace bool } // ErrExist when to exists
type WalkOptions struct {
	MaxDepth int                     // deepest listed path in segments; a dir at the limit is listed, not entered; 0 = none
	MaxFiles int                     // over it: ErrTooManyFiles with the first MaxFiles; 0 = none
	SkipDir  func(rel string) bool
}
type WatchOptions struct {
	Names    []string
	MaxDepth int
	SkipDir  func(path string) bool
	Latency  time.Duration
}
type Pending struct{ /* renameio.PendingFile, service, name */ }
func (p *Pending) Write(b []byte) (int, error)
func (p *Pending) Commit() (Info, error) // fsync, rename, dir fsync
func (p *Pending) Discard() error        // idempotent; safe after Commit

type Info struct {
	Size    int64
	Mode    fs.FileMode
	ModTime time.Time
	Dir     bool
	Version Version // size-mtimeNanos (taskfiles rule)
	Refused string  // "symlink", "hard link", "special file" under PlainOnly/Refuse; "" usable
}
type Entry struct{ Name string; Info } // Name: rel under the walked dir (slash), or base for ReadDir
```

### Rules (doc comment, one line each)

1. **Names.** Rooted: clean relative slash path, no empty, `.` or `..` segment, not absolute, else
   `ErrInvalidPath`. Host-wide: absolute, `filepath.Clean`ed, else `ErrInvalidPath`. Untrusted names (agent,
   UI, import archive, shared config repo) always go through a rooted Service.
2. **Contain.** pathsafe's algorithm verbatim: EvalSymlinks of the joined path must stay under the resolved
   root; a dangling leaf symlink is `ErrEscapes`; a missing leaf resolves via its parent. The operation then
   runs through `os.OpenRoot(root)` (opened per call, closed before return: no long-lived fd, no `Close` on
   `Service`), so a link swapped in after the check still cannot escape (TOCTOU).
3. **Refuse.** taskfiles' walk verbatim: `Lstat` each component through the `os.Root`; a symlink is
   `ErrUnsafe`; a non-dir mid-component is `ErrNotExist`. Reads open with `openFlags` (`O_NOFOLLOW|O_NONBLOCK`)
   and fail `ErrUnsafe` unless `os.SameFile(lstat, fstat)`.
4. **PlainOnly.** Hard link (`nlink > 1`) and special files are `ErrUnsafe` on Stat, Read, Write; `Walk` and
   `ReadDir` list them with `Info.Refused` set and never follow or read them.
5. **Atomic write.** `renameio.NewPendingFile` in the target dir (`WithRoot` when rooted), parents created
   with the dir perm, write, `CloseAtomicallyReplace` (file fsync, rename), then fsync the parent dir (open,
   `Sync`, close; darwin `Sync` is `F_FULLFSYNC`). A dir-fsync failure returns the error; the new content is in
   place (documented). Temp names are renameio's dot-prefixed `.<base>NNN` in the same dir. `IfVersion`
   compares before writing (same race window as today, documented).
6. **Perms.** File 0644, dir 0755; `Private` 0600 / 0700. `Perm` overrides; `Static` uses
   `WithStaticPermissions` (umask ignored, re-tightened); `KeepPerm` uses `WithExistingPermissions`; default
   `WithPermissions` (umask honoured, today's `renameio.WriteFile` behaviour).
7. **Caps.** `Read(name, max)`: `max` 0 means `Policy.MaxRead`, else `DefaultMaxRead`. Size over cap before
   open, or growth past it while reading, is `ErrTooLarge`. `Walk` `MaxFiles` is `ErrTooManyFiles` with the
   first entries returned.
8. **Errors.** Every error is `*fs.PathError{Op, Path, Err}`: `Path` is the rel name (rooted, never leaks the
   root) or the absolute name (host-wide); OS failures keep the errno in `Err`, so `os.IsNotExist` and
   `errors.Is(err, fs.ErrNotExist)` both keep working at the 35 existing sites. Policy failures put a sentinel
   (wrapped with detail via `%w`) in `Err`: `ErrInvalidPath`, `ErrEscapes`, `ErrUnsafe`, `ErrTooLarge`,
   `ErrTooManyFiles`, `ErrConflict`. `ErrNotExist = fs.ErrNotExist`, `ErrExist = fs.ErrExist`. Remove of a
   missing name is nil.
9. **Rename.** Same Service only; parents of `to` created; fsync both parent dirs. `NoReplace` checks then
   renames (today's taskfiles race, documented). Cross-Service moves use `Copy` then `RemoveAll`.
10. **Copy.** fsmove semantics kept: dirs, regular files and symlinks (kept as links) with source modes,
    through `to+".tmp"`, verified (type, size, sha256, link target), then renamed. Under `Contain`/`Refuse`
    a symlink found in `from` is copied as a link, never followed.
11. **Watch.** Each name goes through `Path`, then `fswatch.Watch` with the absolute roots; events keep the
    absolute caller spelling (P699 contract unchanged). `Event`, `Op`, `Create..Meta`, `Watcher`, `Unlimited`,
    `Debouncer`, `NewDebouncer` are aliases, so consumers drop the fswatch import.

### Injection and testability

`Service` holds no process state beyond its `Policy` and resolved root. Owners build the rooted Service they
need in their existing constructor from the dir they already receive (`store.NewLocal(root)`,
`codeworkspace` per worktree root, `configsync.New` from `Options.Home` (config dir root), `agentport`
backup dir, `bridge` proof shot folder), and keep it in a field. Host-wide paths (user-picked files, repo
roots, `.git` internals, Kira's own files named from validated config names) use `fileservice.Host()`. No
constructor signature outside those owners changes, so test constructors stay as they are. Tests run on real
temp dirs, as the flow tests already do; the service's own tests cover path safety. No fake file system: no
consumer test needs one, and a fake would hide exactly the OS behaviour (symlinks, `nlink`, rename) the
service exists to get right.

### What stays as-is

- `taskfiles/store.Store` interface (object-storage seam) and its sentinels and messages: `Local` becomes a
  thin adapter over a `Policy{Root, Symlinks: Refuse, PlainOnly: true}` Service and maps service sentinels
  to `store.ErrNotExist`, `ErrExist`, `ErrInvalidPath`, `ErrUnsafe`, `ErrTooLarge`, `ErrTooManyFiles`,
  `ErrConflict` with today's message text (agent-facing `fileErrors` read them). `ValidRel` stays as the
  store's exported check, delegating name rules to the service's rule 1 helper.
- `store.Blobs` keeps its API; its `Put` uses `Write` (now fsynced) under a `Private` rooted Service;
  `Sweep` uses `Walk` and keeps the `.put-*` stale-temp rule plus renameio's `.<key>NNN` temps (both
  dot-prefixed; match on leading `.`).
- `configfs.Folder` API; it calls `fileservice.Host()` with names checked by `Folder.path`.
  `configfs.TextHash`, `MaxFileBytes`, `ErrTooLarge` stay; `Folder.Read` maps `fileservice.ErrTooLarge` to

## Risks

- **Error text drift.** Rooted errors now name the rel path. Grep flow tests and catalog params for
  asserted messages with absolute paths before group 2; store sentinels keep their text (adapter maps).
- **`os.Root` semantics.** It refuses `..` escapes and absolute symlinks that leave the root even when
  pathsafe would allow a link back inside via an absolute target. Contain check passes first; if `os.Root`
  refuses a path the check allowed, map to `ErrEscapes` and add the case to `path_test.go`. Worktrees whose
  root is itself a symlink: root resolved once in `New`, as `NewLocal` does.
- **Per-call `OpenRoot`.** One extra `openat` per operation. Walk and Copy open once per call. Negligible
  against fsync; do not cache roots (fd lifetime across per-task stores).
- **Dir fsync cost.** One extra fsync per write. Hot writers: task watch passes, config saves, blob puts
  (each already fsyncs the file). Acceptable; note it in the ARCHITECTURE section.
- **Overlap with P701, P702, P703.** P700 edits call sites in `ade/taskwatch.go`, `ade/detailssubmit.go`,
  `ade/taskfiles.go` (P703), `ade/worktreedir.go`, `gitsession/worktree*.go`, `gitops/conflict.go`,
  `internal/agentmcp/mcp.go` (P702, P703), `scriptruns/sandbox.go`, `ade/runs.go`, `ade/launches.go`,
  `ade/recover.go` (P701). Hunks are call swaps, but those phases rewrite the same functions. Recommend
  batching P700 only with P704, P705, P706 (no Go overlap: P705's `mobileweb/static.go` is embed, untouched).
  If batched with P701 to P703 anyway, whichever lands second re-applies the swap on rebase; G8 catches a miss.
- **Hidden callers via `exec`** (`cp -a`, `rm`) are out of G8's reach; none found in moved packages outside
  test tooling (flowharness `cp -a`).
- **Disk.** 7.9 GB free at plan time (`df -h /`); aim for 6 GB. Use a per-stream build temp:
  `export GOTMPDIR=/tmp/p700-gotmp; mkdir -p $GOTMPDIR`; remove it at phase end. Run only the targeted tests
  above, one Go suite at a time; never the full `go test ./...` (chapter full run does that).
