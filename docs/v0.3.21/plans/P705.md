## 2. Design

### 2.1 Backend: script runs

- `internal/mobileweb/scriptruns.go` (new): `phoneRun(r any) (any, error)` keep-list projection
  over JSON object, so phone never sees cwd, command, prompt, params, tools, terminalId, outputTail,
  lastError, model, provider, sessionId. Keep: `id`, `scriptName`, `color`, `kind`, `trigger`,
  `state`, `createdAt`, `startedAt`, `finishedAt`, `taskId`, `taskTitle`, `branchId`,
  `branchLabel`, `resumable`, `outcome.{status, reason, exitCode}`. Keep-list, not drop-list: new
  `Run` fields stay private by default.
- `Config.ScriptRuns func(ctx context.Context, limit int) ([]any, error)` (`server.go`). Route
  `read("/api/runs", ...)` in `routes.go`: newest 30, each through `phoneRun`, `{"runs": [...]}`.
  Nil seam answers empty list (server build, fixtures without runs).
- Channel name: move `ChannelScriptRunsChanged` to `internal/appevent` next to
  `ChannelAgentSessions` (`mobileweb` cannot import `bridge`, which imports it); `bridge` keeps
  `const ChannelScriptRunsChanged = appevent.ChannelScriptRunsChanged`. Add
  `appevent.ChannelScriptRunsChanged: phoneRun` to `eventChannels`.
- Wiring: `bridge/mobile.go` adds field `ScriptRuns` and copies it in StartFn; `appwire.go`
  mobile block passes `func(ctx, n) { w.ScriptRuns.List(bridge ListArgs{Limit: n}) }` mapped to
  `[]any`. `w.ScriptRuns` is built at `appwire.go:527`, before mobile block.

### 2.2 Backend: computer summary

- `Config.Computer func(ctx context.Context) (any, error)`. Route `read("/api/computer", ...)`
  returns `{docker: {state, reason, running, stopped, total} | null}`. Message, endpoint, version,
  images stay off phone (endpoint can hold a socket path).
- `appwire.go` passes closure over `w.Docker.Status(StatusArgs{})` (no forced refresh). `w.Docker`
  nil (Docker module off) yields `docker: null`.
- No push: Docker pushes are per window. Client polls 30 s only while Activity screen is mounted
  and document visible, plus refetch on SSE reconnect.
- Field name `computer` leaves room; only Docker ships in P705.

### 2.3 Shared wire schemas

`packages/shared/domain/mobile.ts`: add `phoneRunSchema`, `phoneRunsSchema`,
`phoneComputerSchema` (zod, `/*#__PURE__*/`, reuse `scriptRunStateSchema` from
`domain/scriptRuns.ts`). Go side has no schema test today; flow contract (section 3) pins shape.

### 2.4 Frontend reads

- `frontend/mobile/api/adeReader.ts` (or new `api/status.ts` if reader file is ADE-only): `runs()`
  and `computer()` over `http.ts`, parsed with section 2.3 schemas.
- `frontend/mobile/state/usePhoneStatus.ts` (new): TanStack Query `usePhoneRuns` (key
  `['phone', 'runs']`) and `useComputer` (key `['phone', 'computer']`, `refetchInterval` 30 s
  gated by `useDocumentVisibility`, `enabled` only while consumer mounted). `onChannel(
  'kira:scriptRuns:changed')` upserts the run into cached list via `setQueryData` (newest first,
  cap 30), no refetch. Add channel to `events.ts` CHANNELS. Reconnect invalidates `['phone']`
  beside existing `['adetask']`.
- `useAgentsModel.ts`: read change requests (`useChangeRequests` from same shared reader queries
  board uses) and extend `PlanCard` with `sessions` (all task sessions, `sessionView` rows),
  `run` (current run state, started-at), `jira`, `branchRequest`, `branches` (per branch: tag
  label and tone from `branchTag`, ahead, behind, dirty, PR state, checks). Build `BranchGraph`
  once per board via `buildBranchGraph`. Add `agents` (from `agentsSummary` over all sessions)
  and `repos` state for Activity. No new Pinia store: state is derived query data; existing agent
  sessions store stays the one store.

### 2.5 Screens

- New `screens/ActivityScreen.vue`, route `/activity` (`router.ts`), fourth tab in `TabBar.vue`
  (label `mobile.tabs.activity`), small pulsing dot (Tailwind `animate-pulse`) when any agent is
  working. Sections:
  - Agents: summary line (n working, n waiting, n idle), rows by `byRunningOrder`: task title,
    where (branch label), activity label, ago, TUI/headless badge, unseen dot. TUI row links to
    `/terminal/:id` only when `/api/me` grants agent input (existing permission flag).
  - Runs: running first (`RunElapsed`-style ticking duration via shared `useNow`/interval already
    in model), then last finished/failed, each: script name, task title, state badge, outcome
    reason or exit code.
  - Computer: connection (live/reconnecting/offline), last update age, repos (name, updating
    spinner, last fetch ago), Docker (ok with running/stopped counts, or unavailable with reason).
- `PlanTaskCard.vue` collapsed adds: sessions glyph plus count (working tone), current run line
  (state, duration; failed reason), Jira key, branch-request chip. Expanded adds: `PhoneBranchRow`
  (new `components/PhoneBranchRow.vue`) per branch, all task sessions (not only running TUI),
  task script runs (filter `['phone','runs']` by taskId).
- `PhoneBranchRow` reads glyph/tone from `plan/glyphs.ts` and `panel/prState.ts` directly, one
  call site, so P706 swaps it for shared component in one edit. Drop the "Desktop-only" note on
  `plan/glyphs.ts` header comment (it is now shared).
- Need You: add Activity-only entries, not new needs kinds: shared `buildNeedsYou` stays unchanged
  (desktop parity). Unseen and failed script runs surface in Activity with an Activity tab dot.
- Reuse pure desktop modules by import (`agentsSummary`, `sessionView`, `activity.ts`,
  `taskSessionsOf`, `branchTag`, `buildBranchGraph`, glyph maps). Check each import is free of
  `@bindings` (mobile build has no alias); `bun run build:mobile` fails loud if not. Any module
  that drags bindings gets its pure part split out in the same commit, never copied.

### 2.6 Connectivity, push not refresh

- Remove Refresh button from `AppShell.vue`. Header shows "Updated 2 min ago" (`useTimeAgo`) next
  to status dot when connection is not live; last-update time is stamped by any SSE frame
  (`ready`, ping, event) in `events.ts`, exposed beside `connection`.
- Reopen EventSource on `useDocumentVisibility` going visible and `useOnline` going true, when
  state is not open (iOS freezes background sockets). Reconnect path already resyncs.
- Empty/loading/offline: every new section uses existing `EmptyState`, `QueryState`, `Alert`
  patterns; offline shows cached data dimmed plus existing banner, never a blank screen.

### 2.7 Frontend rules

Tailwind utility classes only, no scoped `<style>`. Primitives from shadcn-vue (`Badge`, `Button`).
VueUse for visibility, online, interval, time ago. TanStack Query for new reads. No new Pinia store
(section 2.4). `<script setup lang="ts">` everywhere. No new dependency. Bundle: record
`dist-mobile/assets` total before and after (`du -b`), state both in Result; growth over 25 KB
gzip means an import pulled desktop code it should not, fix before done.

### 2.8 i18n

`packages/theme/src/i18n/en.json` `mobile` namespace: `tabs.activity`, `activity.*` (section
titles, empty states, agent counts with plural forms, run states reuse existing `space.` run labels
where present), `shell.updatedAgo`, `computer.docker.*`. Remove `refresh` usage only (key
`common.action.refresh.label` is shared, keep it).
