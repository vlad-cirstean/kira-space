## 2. Design

### 2.1 Window shape

One Files window per task (same scope as the tab: branch picker for several worktrees). Opening
it again focuses it. Never restored on relaunch. Closes when the task is archived.

Storage: in-memory registry with a prefixed key, the host view pattern, not a new table.
Reason: a files window pins nothing and holds no state worth a row; the review table exists for
review-session pinning. A table would add a schema migration and the minor-bump legacy rules for
no gain. What is reused from the review window: the bridge func fields and focus-or-open flow,
the task-lock open in the engine, window order, title, Archive close, `Ephemeral` close, boot
purge, the frontend boot query plus store plus `App.vue` branch, and the window layout primitives
(`TitleBar`, `windowBody`, `paneFrame`).

### 2.2 Backend

New `internal/ade/fileswindow.go`:

- `const FilesWindowKeyPrefix = "adefiles-"`; `func IsFilesWindowKey(key string) bool`.
- `filesWindows` (mutex, `byKey map[string]string` key→task, `byTask map[string]string`), a field
  on `TaskBoard` (zero value usable).
- `type FilesWindowOpen struct { Key, Title string; Order int; Existing bool }`.
- `(b *TaskBoard) OpenFilesWindow(ctx, taskID) (FilesWindowOpen, error)`: nil `Deps.Windows` →
  `invalid("files windows are not available")`; take `taskMu(taskID)`; `loadTaskCtx` (archived or
  missing task errors as today's task calls do); registry hit → `{Key, Existing: true}`; else order
  max+1 over `Windows.List()`, `Windows.Create`, register, title from backend key
  `backend.space.ade.filesWindow.title` (`Files · {task}`, task title as `taskTitle` shows it on the
  board; plain `i18n.T` like `hostview.go:268`).
- `(b *TaskBoard) FilesWindowTarget(key) *adewire.TaskFilesWindowTarget`: `{TaskID}` or nil.
- `(b *TaskBoard) ForgetFilesWindow(key)`: drop the entry and `TaskFilesClose` every branch of
  that task (the frontend `onUnmounted` release never runs on a native close). Idempotent.
- Archive: replace `Deps.CloseReviewWindows func(taskID string)` with `Deps.CloseWindow func(key
  string) bool`. Rename `closeReviewWindows` to `closeTaskWindows` (`review.go:341`, caller
  `archive.go:196`): close each `ReviewWindows.KeysByTask` key and the task's files key, then
  `ReviewWindows.DeleteByTask` and `ForgetFilesWindow`. Delete `closeTaskReviewWindows`
  (`appwire/wire.go:172-185`); `appwire.go:548` passes the `CloseWindow` closure it already builds.

Bridge (`internal/bridge/adetask.go`, beside the review methods):

- `OpenFilesWindow(ctx, adewire.TaskArgs) (bool, error)`: validate `taskId`; nil
  `OpenWindow`/`FocusWindow` → `adeTaskInvalid("files windows are not available")`. Existing key:
  `FocusWindow(key)` true → false; false (stale entry) → `Engine.ForgetFilesWindow`, delete the
  row, open again (host view `openTarget` logic). New: `OpenWindow` plus `SetWindowTitle`, true.
- `FilesWindowTarget(ctx, adewire.WindowKeyArgs) (*adewire.TaskFilesWindowTarget, error)`.
- `adewire.TaskFilesWindowTarget struct { TaskID string \`json:"taskId"\` }` in
  `bridge/adewire/wire.go`; regenerate bindings and `frontend/src/ade/v2/wire.ts`.

Wiring:

- `main.go:ephemeralWindowKey` adds `ade.IsFilesWindowKey(key)`, so close deletes the row and boot
  purges leftovers. Update its comment.
- Append `w.AdeBoard.ForgetFilesWindow` to `w.OnWindowClosing` in appwire after
  `wireDbServices` assigns it (`dbmodule.go:333`), not in `main.go`, so the flow harness
  (`flowharness/harness.go:581-588`) runs it.
- Server build: `OpenWindow` stays nil there, so the call answers the contract error, as review.

### 2.3 Quiet entry point

Pick: a small icon button in the task panel header actions, `AdeTaskPanel.vue` `#actions`, after
the Review button and before the More (ellipsis) button. `TooltipIconButton icon="files"`,
`data-testid="ade-panel-files"`, tooltip `space.ade.panel.files.tooltip` ("Open files in a
window").

Why: the task panel is where the tab lived, so users find it in the same place; an icon has no
label and no colour, so it is visibly below the labelled Review button; it is reachable by Tab
order and has a tooltip. Declined: command palette entry (the palette has no task-scoped
commands; a task needs a selected panel anyway, so it would duplicate the icon), keyboard shortcut
(a new global chord for a secondary view; can come later). Not in `useTaskMenu` (right-click and
the More button share it) and not on board cards.

States: shown when the task has a named branch (same `v-if` shape as Review's `choices.length`);
disabled through `TooltipDisabledTrigger` with tooltip `space.ade.files.noWorktree.empty` when no
branch has a worktree. Click calls `useOpenFilesWindow` (new, `ade/v2/queries.ts`, mutation key
`['adetask', 'openFilesWindow']`); an error goes to `ui.actionError[taskId]` like `useReviewCode`;
focus returns to the button.
