## 2. Decisions

- **Repo awareness key:** YAML `outside_repo: true`, wire `outsideRepo: boolean`, default `false` (repo aware). The flag is inverted on purpose: snapshots of started tasks unmarshal a missing field as `false`, so existing tasks keep running in their worktrees. The inspector shows it as a **Repo aware** switch (on = `outsideRepo: false`).
- **Where `outside_repo` is allowed:** agent and script steps; manual steps only with `session: true` (same pattern as `agent`/`settings`). Not on review steps: a review needs a branch.
- **Outside-repo semantics:** one run on `taskTarget`, cwd the task folder, regardless of the task's branches. `runs_on` is refused on such a step (one concept, no dead combinations). `{repo}` and `{branch}` placeholders are refused in its `prompt`/`command` (they would expand empty). Manual session: cwd the task folder, no repo lines, no `--add-dir`.
- **Script sandbox:** `sandbox` allowed on script steps. Script default is `off`, so every existing script step behaves as today (unconfined, no badge row). Agent and review default stays `write`. Canonical off value is `{access: off, read: [], allow: [], network: true}`, which is what the parser already yields for `sandbox: {access: off}`.
- **Manual session sandbox: out of scope, called out.** The sandbox does not cover TUI sessions (`ARCHITECTURE.md:2514`); confining an interactive session is a separate subsystem (Take over, permission prompts, the PTY launch). The orchestrator raises this with the user rather than P510 narrowing silently. If the user wants it, it becomes its own phase.
- **Snapshot compatibility:** script steps in existing snapshots carry the old `write` default that was never applied. Migration `0068` rewrites them to the off value. `decorateTask` compares the live hash with the hash of the re-marshalled snapshot, so added wire fields never flip `workflowOutdated` on started tasks.
- **Tab order:** desktop ADE shell becomes Needs you, Later, Plan. Mobile `TabBar` gets the same order for consistency (same three tabs, same labels). The default view stays `plan`. If the orchestrator wants desktop only, drop W9's mobile half.
- **Libraries:** shadcn primitives already in `packages/theme` (`Switch`, `Field*`, `Input appearance="inline"`, `NativeSelect`, `Textarea`, `Collapsible`, `DropdownMenu`, `Alert`), theme `SecondaryTabs` and `SectionHeading`, `usePersistedState` from workbench. No new dependency. Tailwind 4.3 container queries (`@container`, `@[24rem]:`) for the narrow-pane fallback.
