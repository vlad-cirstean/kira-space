## Root causes

1. Card fully coloured. `plan/taskTint.ts:7-12` (new in `107933fca`) fills the whole card
   (`color-mix … 10%` background) and tints all four borders. Used at `plan/AdeTaskCard.vue:119`
   and on span rows `plan/AdeDayBand.vue:198`. `AdeTaskCard.vue:99-100` dropped `border-l-3` and
   the transparent border: v0.3.8 had `cursor-grab border border-l-3`, `border-transparent` (focus
   when selected) and `:style="{ borderLeftColor: card.color }"`. Span rows had
   `border border-l-3 border-border` plus `borderLeftColor: s.color`.
2. Card top line cut off; user must widen the task list to full screen. `807558222` made the card
   head line (`AdeTaskCard.vue:137-271`) a row of fixed `shrink-0` columns from
   `plan/cardColumns.ts` (lead `w-11`, status `w-24`, flags `w-10`, segs `w-20`, label `w-28`, bar
   `w-21`), and keeps empty spacers when a task has no workflow (`AdeTaskCard.vue:184`, `:210`).
   About 510px of fixed width before chips, meta and the right-side buttons. `Card` is
   `overflow-hidden` (`:117`), so with the panel open the Change base, Review code and action
   buttons are clipped off. v0.3.8 had one `min-w-4.5` lead, status `max-w-24 shrink-0`, and
   segs/label/bar only when `p.hasWorkflow`.
   Shell top bar (user detail): `shell/AdeShell.vue:110-113` nav is
   `grid grid-cols-[1fr_auto_1fr]`. `1fr` tracks have `min-width:auto`, the capture box is a fixed
   `w-72` (`shell/AdeCaptureBox.vue:45`), both `TabsList`s never shrink. Nav min-content (6 wide
   tabs + 288px input + Add) exceeds a narrow window, so the outer tabs are cut off. Template is
   unchanged since v0.3.8 (`git diff v0.3.8..HEAD -- shell/AdeShell.vue` touches only script), so
   the fix is new: shrink or wrap, keep v0.3.8 look at normal width.
   Not causes (checked): `AdePlanView.vue` root uses `paneFrame` (`min-w-0`), plan header
   `AdePlanRepos.vue:30` already `flex-wrap`, `panel/AdePanelPane.vue` (width default half the
   row, min 340) unchanged since v0.3.7.
3. Branches take too much space at the start. Card branch rows gained a fixed `w-5` lead cell
   before the depth indent: `plan/AdeBranchRow.vue:281-283` (`data-testid="ade-branch-lead"`,
   `557738b17`/`807558222`), moving `AdeAttention` from after the tip (v0.3.8 `:420`). The card
   head lead also grew from `min-w-4.5` to `w-11` (two cells). Panel size is unchanged since
   v0.3.7 (see 2), so the space is the row lead, not the panel.
4. Today looks like any other day. `107933fca` removed the today ruler border
   (`border-r-tone-amber-solid`, now `border-r-border` at `AdeDayBand.vue:107`), set the dot to
   `border-fg bg-fg` (`:72`) and made the label an inverted `bg-fg text-bg` chip (`:119`). The band
   body has no tint, so today's row reads like the rest. User decision: today is a brighter,
   subtle neutral grey than other days. Not yellow, not strong.
5. New requirement: timeline gutter costs width. `AdeDayBand.vue:105-127` renders a fixed
   `w-15 shrink-0 border-r-2` ruler column (label, hours, dot) beside every band; three siblings
   indent by the same 60px: `AdeHistoryControl.vue:14` (`ml-15`), `AdePlanView.vue:447` and
   `:459` (`ml-15`). Replace with one date heading row per band.
