  (`AdePlanView.vue:432`).
- Drag drop target resolves nearest slot from geometry (`usePlanDrag.ts` header comment); no
  constant depends on these gaps.

## Changes

### 1. Task colour as the border, stronger selection (task list)

`apps/kira-space/frontend/src/ade/v2/plan/taskGrid.ts`: replace the `TASK_EDGE` constant and its
comment, add two:

```ts
/** Task colour on a card or span row: its 1px border. The row sets `--task-color` inline. */
export const TASK_EDGE = 'border border-(--task-color)';
/** Selected card or span row: 2px outline in the task colour flush with the border, so the frame
 *  reads 3px without reflow. */
export const TASK_EDGE_SELECTED = 'outline-2 outline-offset-0 outline-(--task-color)';
/** Card whose branches must rebase when the selected task merges. */
export const TASK_EDGE_RIPPLE = 'border-dashed';
```

`apps/kira-space/frontend/src/ade/v2/plan/AdeTaskCard.vue`:

- Import `TASK_EDGE_RIPPLE`, `TASK_EDGE_SELECTED`.
- `boxClass`: `['bg-chrome cursor-grab', TASK_EDGE, GROUND_CARD, selected.value ?
  TASK_EDGE_SELECTED : inRipple.value ? TASK_EDGE_RIPPLE : '']`. Drop the unused `const c`.
- `<Card>`: `:style="{ '--task-color': card.color }"` replaces `borderTopColor`.
- Head keeps `GROUND_SELECTED` fill when the task itself is selected. Selection now reads as fill
  plus a thick frame in the task's own colour; no grey edge.

`apps/kira-space/frontend/src/ade/v2/plan/AdeDayBand.vue` span row `<Button>`:

- class: drop `border border-border`; `:class="[TASK_EDGE, ui.selectedTaskId === s.taskId &&
  TASK_EDGE_SELECTED]"`; `:style="{ '--task-color': s.color }"`. `data-[selected]:bg-select` stays.
  `cn` in Button merges `border-transparent` (cva base) with `border-(--task-color)`, as it does
  with `border-border` today.

Outline, not a wider border: a 3px border would shift every card and row by 2px on select. Outline
needs no layout, follows `rounded-kira` in WebKit, and is not a focus style (`check-theme-classes`
only bans `focus*:outline-[2-9]`). Card itself is not focusable; head keeps its `focus-ring`.
Band drop area keeps ≥ 6px bottom padding (below) and `px-3` side room, so the 2px outline is never
clipped by the scroll pane.

### 2. Task detail: colour line below the title, no gap before the tabs

`apps/kira-space/frontend/src/ade/v2/panel/AdePanelFrame.vue`:

- New optional prop `color?: string`. Inside `ade-panel-head`, after `<slot name="header" />`:
  `<ColorLine v-if="color" data-testid="ade-task-line" variant="under" :color="color" />`
  (`under` = absolute bottom of the relative head, directly above the tab row). Update the file's
  comment: header slot, task colour line under it, then tab row.

`apps/kira-space/frontend/src/ade/v2/panel/AdeTaskPanel.vue`:

- Remove the `ColorLine` element and import; pass `:color="card.color"` to `AdePanelFrame`.
- `DetailHeader`: add `flush` and `class="px-3 pt-2 pb-0.75"`. Bottom 3px is exactly the line's
  height: line sits right under the title row (or under the alerts/forward bar when present), tabs
  4px below it (`PanelBar` `py-1` unchanged). Title row to tab chips drops from ~18px to 7px, line
  included.

`apps/kira-space/frontend/src/ade/v2/panel/AdeBranchPanel.vue`: same as task panel for consistency
(branch panel is the task detail in branch mode): drop its `ColorLine` and import, pass
`:color="card.review ? 'var(--kira-info)' : card.color"` to `AdePanelFrame`, `DetailHeader` gets
`flush class="px-3 pt-2 pb-0.75"`.

`AdeArchivedPanel.vue`: no change (no colour line; gains the empty-wrapper fix below for free).

`packages/theme/src/components/DetailHeader.vue` line 69: default-slot wrapper class
`mt-1 flex flex-col gap-1.5` becomes `mt-1 flex flex-col gap-1.5 empty:hidden`. CSS `:empty` ignores
comment nodes, so a slot whose children are all `v-if`-false leaves no 6px phantom gap. Pure fix for
every caller: a wrapper with real content is unchanged.

### 3. Plan tab gaps

- `AdeDayBand.vue:205`: drop `:class="i > 0 ? 'mt-2' : undefined"` from `AdeTaskCard`. Same-day
  cards sit 8px apart (`gap-2`), not 16px.
- `AdeDayBand.vue:144`: non-empty drop area `pb-2 pt-1` becomes `pb-1.5`. 6px stays under the last
  row: day bar ends 4px above band bottom (`ade-v2-plan.spec.ts:795-797` requires last row ≤ bar
  bottom) and the 2px selected outline fits.
- `AdePlanView.vue:432`: `px-3 pb-4 pt-3` becomes `px-3 pb-4 pt-1`. Bottom keeps scroll room.
- Kept: band head `h-row` (holds date and rule), card internals (pinned row heights, 44px head), the
  `mt-2` before load-all/collapse buttons (separate controls, not list gaps).

No new i18n, no new store, no scoped style; Tailwind utilities only.
