## Findings (codegraph)

- Note and handover bodies render in full (`AdeNoteBody`, no height cap). An agent handover or a
  pasted note runs to hundreds of lines; contract `ade-notes` `AdeTaskService.AddNote#large` is a 12 KiB
  body. That is the main scroll cost.
- Double padding: `Card` `inset` is `gap-1.5 px-2.5 py-2`; `AdeNoteEntry` renders `AdeNoteBody`
  without `flush`, so `noteProse` adds `px-3 py-2` inside the card padding (`notes/prose.ts:4`).
  `TaskCreateBody.vue` already passes `flush`.
- Spacing: Details tab `gap-3 p-3` (`AdeDetailsTab.vue:26`), chain entries `gap-2`
  (`AdeTaskChain.vue:79`).
- `AdeAuditEntry.vue:116-133`: statement `line-clamp-2` with an always-shown "Show all"/"Show less"
  link, even for a one-line statement. Every audit row spends a line on a dead toggle (fixture
  statements are 38-50 chars).
- No generic multi-line clamp exists. `TruncatedText.vue` (theme) is single-line with tooltip.
  `CommitMeta.vue` and `AdeAuditEntry.vue` each hand-roll a toggle. reka `Collapsible` (theme
  `ui/collapsible`) hides content entirely: `CollapsibleContent` unmounts or hides when closed, so it
  cannot show the first lines of collapsed content. Declined for that requirement; plain `Button`
  with `aria-expanded`/`aria-controls`.
- Copy: `common.action.showMore.label` ("Show more") and `common.action.showLess.label` ("Show less")
  exist; ARCHITECTURE copy table names "Show more" for revealing. No catalog change.
- `Details` panel expansion must survive tab switch: tabs remount the Details tab, and
  `useKeptScroll` restores the old scroll offset, which lands wrong if expanded entries come back
  collapsed. State goes in Pinia, keyed by entry id.

## Changes

### 1. `packages/theme/src/components/ClampedContent.vue` (new)

Multi-line counterpart of `TruncatedText`. `<script setup lang="ts">`, Tailwind classes, no scoped
style.

- Props: `lines?: number` (default 6), `toggleTestid?: string` (default `clamped-content-toggle`).
  Model: `const expanded = defineModel<boolean>('expanded', { default: false })`.
- Template:
  - Root `<div class="flex min-w-0 flex-col items-start gap-0.5">` (attrs fall through, so callers
    pass `data-testid`).
  - Box `<div :id="id" ref="box" class="w-full min-w-0" :class="clamped && 'overflow-hidden
    mask-b-from-60%'" :style="clamped ? { maxHeight: `${limit}px` } : undefined" :data-clamped="clamped"
    data-slot="clamped-content-box">`, inner `<div ref="inner"><slot /></div>`.
  - When `overflowing`: `<Button variant="link" size="inline" :aria-expanded="expanded"
    :aria-controls="id" :data-testid="toggleTestid" @click="expanded = !expanded">` with
    `t('common.action.showLess.label')` or `t('common.action.showMore.label')`.
- Script:
  - `id = useId()`.
  - `limit = ref(0)`, `overflowing = ref(false)`; `clamped = computed(() => overflowing.value &&
    !expanded.value)`.
  - `useResizeObserver(inner, measure)` (VueUse; fires on width and content change). `measure`:
    read `getComputedStyle(inner)`; `lh = parseFloat(lineHeight)`, `NaN` (value `normal`) falls back to
    `1.5 * parseFloat(fontSize)`; `limit = Math.round(props.lines * lh)`; `overflowing =
    inner.scrollHeight > limit + 1`. Inner is never clamped (box is), so this measures the same
    whether expanded or not, and short content shows no link.
  - Comment (one line): why inline `maxHeight` (limit derives from measured line height).
- Clicks inside content never toggle, so text selection and links keep working.
- Fade: Tailwind 4 `mask-b-from-60%`. Implementer confirms in built CSS that WebKit gets a working
  mask (`mask-image`, unprefixed since Safari 15.4); if not, use arbitrary
  `[mask-image:linear-gradient(to_bottom,black_60%,transparent)]`.
