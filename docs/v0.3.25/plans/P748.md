# P748: Proof grid lines, title link to window, collapsed proofs in Details

Spec: `docs/v0.3.25/SPEC.md` § P748. Base: `2f5d6770c` (stream/P748 off chapter/v0.3.25).

## Terms

- **Proof window**: `studio/proof/ProofWindow.vue`. Each step tab mounts `ProofStepView.vue`
  (`ProofCompare.vue` mounts it too); table, document and key-value steps render through
  `views/console/ConsoleResultGrid.vue` (table via `ConsoleSlickGrid.vue`).
- **Proof entry**: one proof in the task panel Details tab, `ade/v2/details/AdeProofEntry.vue`,
  listed by `AdeTaskChain.vue`.

## Findings (codegraph)

- Grids: `slickTheme.css:253-256` draws `.slick-cell` right and bottom lines in `--kira-border`
  (`#323237`, about 1.3:1 on `--kira-bg` `#1b1b1e`), so rows barely separate. Header lines
  (`:49-54`, `:143`) and right-aligned cells (`:347`) use the same token. Key-value rows
  (`ConsoleResultGrid.vue:520-597`) have no line at all: two cells over the same background.
  Document rows (`DocumentRow` in `ConsoleResultGrid.vue:481-516`) have none either. All row boxes
  are absolute virtual rows (`VIRTUAL_ROW_CLASS`: `absolute top-0 left-0 w-full`); document heights
  come from `useDocumentResultHeights`, key-value heights from `measureKvRow` in proof mode.
- Title link: commit `f75a4ce0f` (`feat: full, selectable text in proof view and proof tab`, P736)
  replaced the name `<Button variant="link" size="inline" data-testid="ade-proof-open">` with a plain
  `<span data-testid="ade-proof-name">` and moved the open action to a header
  `TooltipIconButton` (`link-external`, same testid). Found with
  `git log --all -S'ade-proof-name' -- .../AdeProofEntry.vue`. P736's reason: text inside a
  `<button>` cannot be selected in WebKit.
- Auto-expand: P736 (`docs/v0.3.24` plan, commit `b37fb0d5d`) made the Details entry show every step
  with diagram steps drawn inline at full height (`AdeProofDiagramStep.vue` `fit="content"`, no
  `h-64` cap), and the proof window open every document and nested field and grow key-value rows
  (`ConsoleResultGrid` prop `autoExpand`, `rows.ts` `openNested`).
- Expansion state precedent: `state/adeDetailsList.ts` keeps an in-memory `expanded` set
  (`isExpanded`/`setExpanded`); notes use key `handover:<id>` (`AdeNoteEntry.vue:46`). It survives
  the Details tab remounting on a tab switch.
- Collapsible precedent: `ade/v2/review/AdeReviewRemoved.vue` (shadcn-vue `Collapsible`,
  `CollapsibleTrigger`, `CollapsibleContent`, chevron icon). Reka's `CollapsibleContent` unmounts
  closed content, so a collapsed proof fetches no diagram step (`useProofStep`).
- i18n: `common.action.expand.label` / `common.action.collapse.label` and
  `space.ade.proof.entry.open.tooltip` exist. No catalog change.

## Decisions

- Grid lines stay proof-scoped. Spec names the proof tool; console and data tabs keep today's
  lines. A new prop `lined` on `ConsoleResultGrid` (separate from `autoExpand`: different concern)
  is passed only by `ProofStepView`.
- One new colour token, `--kira-grid-line: #4a4a52` (about 1.9:1 on `--kira-bg`; between
  `--kira-border` and `--kira-resize-hover` `#52525b`). `tokens.css` is the only colour source, so a
  literal in a component is not allowed.
- Row lines on Vue-rendered rows are an `after:` pseudo line (absolute, 1px, bottom), not a
  `border-b`: a border adds 1px per row and drifts the virtualizer's translateY offsets on document
  rows, whose heights are computed, not measured. The vertical divider between key-value field and
  value is a real `border-r` (horizontal size only, no height effect).
- SlickGrid cells are not Vue templates, so their lines stay in `slickTheme.css` (existing global
  sheet for SlickGrid DOM), keyed off a host class. No scoped `<style>` block.
- Title link restored: proof name is again a `Button variant="link"` that opens the proof window,
  testid `ade-proof-open`; the header `link-external` icon goes (one open action per header). The
  name keeps P736's full-text wrap (no `truncate`). Trade-off: the name is not selectable (WebKit
  button text); the spec asks for the link. The folder path and summary stay selectable.
- Collapsed by default: header row (toggle, name link, path, pending badge, time, origin session,
  delete) and summary show; the step list (incl. inline diagrams and per-step open icons) sits in
  `CollapsibleContent`. State key `proof:<proofId>` in the existing `adeDetailsList.expanded` set:
  in memory, per proof, survives tab switch, resets on app restart (same rule as clamped notes). No
  store change.
- What stays auto-expanded in the proof window, unchanged from P736: every document and its nested
  fields open on mount, key-value rows grow to content, diagram fills the pane, summary up to 40% of
  the pane. Why: the window is where a proof is read and screenshotted; each capture photographs the
  centre pane as shown, so collapsed data would hide evidence from every shot. The Details entry is
  an index that leads to the window, so it collapses.

## Changes

### 1. Grid lines in the proof window

- `packages/theme/src/tokens.css`: after `--kira-border`, add
  `--kira-grid-line: #4a4a52; /* proof window grids: cell and row lines that read apart (P748) */`.
- `packages/theme/src/tailwind-core.css` `@theme`: add `--color-grid-line: var(--kira-grid-line);`
  next to the resize entries, so `border-grid-line` and `after:bg-grid-line` exist.
- `apps/kira-space/frontend/src/studio/views/shared/slick/slickTheme.css`: append at end of file (an
  equal-specificity rule must come later than `:347` to win):
  ```css
  /* P748: the proof window draws stronger lines so rows and columns read apart. */
  .slick-grid-host.kira-grid--lined .slick-cell,
  .slick-grid-host.kira-grid--lined .slick-header-column.ui-state-default {
    border-color: var(--kira-grid-line);
  }
  .slick-grid-host.kira-grid--lined .slick-header,
  .slick-grid-host.kira-grid--lined .slick-headerrow {
    border-bottom-color: var(--kira-grid-line);
  }
  ```
  Gutter cells are `.slick-cell`, covered by the first rule.
- `apps/kira-space/frontend/src/studio/views/console/ConsoleSlickGrid.vue`: new prop
  `lined?: boolean` (doc comment: proof window, stronger cell lines). Root `:class` object gains
  `'kira-grid--lined': lined`.
- `apps/kira-space/frontend/src/studio/views/console/ConsoleResultGrid.vue`:
  - New prop `lined?: boolean`, doc comment: proof window, visible row and cell lines.
  - Pass `:lined="lined"` to `ConsoleSlickGrid`.
  - Document branch `<DocumentRow :class>`: add, when `lined`,
    `after:pointer-events-none after:absolute after:inset-x-0 after:bottom-0 after:h-px after:bg-grid-line`
    (row is already `absolute`, so it is the pseudo's containing block). Build with `cn()`.
  - Key-value row div: same `after:` set when `lined`. Field cell: add `border-r border-grid-line`
    when `lined` (inside existing `cn()`).
  - Without `lined` every branch renders exactly as today (console, Mongo, Redis unchanged).
- `apps/kira-space/frontend/src/studio/proof/ProofStepView.vue`: pass `lined` to
  `ConsoleResultGrid` next to `auto-expand`.
- Nested field lines inside an expanded document (`DocumentTree`) stay as they are: the ask is grids
  and rows; a tree is neither, and lines per field would double every document's visual noise.
