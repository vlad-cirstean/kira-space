Spec row: `SPEC.md` P765. Owner: "The repo files window. First make it available even if no
worktree, it will open the main one. Second don't auto expand the first row of folder, everything

## Which window

The task Files window (`AdeTaskFilesWindow.vue`, P704). The owner calls it the repo files window.
Candidates checked with CodeGraph:

- `ade/v2/files/AdeTaskFilesWindow.vue` + `AdeTaskFiles.vue` + `AdeFileTree.vue`: the only window
  that shows a repository checkout as a folder tree. Options read `<repo> · <branch>`. It also has

  worktree rule. Not it.

## Root changes

### 1. Availability rule (backend)

Rule: a task row with no worktree opens its repo's main worktree. The window becomes available for
every task row, including rows with a repo but no branch name, because none of them has a worktree.
A task with no rows still has nothing to show.

Definition of "main worktree": git's main worktree for the row's code repo. It is the first record
of `git worktree list` (`gitsession.WorktreeEntry.IsMain`, `internal/gitsession/worktree.go:95`),
the checkout that owns the common git dir. A bare main record does not count, because a bare repo has
no files.

`internal/ade/taskfiles.go`:

- Add `mainWorktree(ctx, entry *gitsession.RepoEntry) (string, error)`:
  - When `!entry.Summary.IsBare && !entry.Summary.IsLinkedWorktree`, use `entry.Summary.Root`. This
    is the common case: the repo was imported at its main checkout, so no extra git spawn runs on
    every file read.
  - Otherwise call `entry.Worktrees(ctx)` and take the `IsMain` record. It must not be `IsBare`.
  - `fileservice.Host().Lstat(path)` must succeed and report a directory. Otherwise return
    `ErrNoMainWorktree`. `ErrNoMainWorktree` also covers a bare main record and an empty list.
- Replace `ErrNoWorktree` with
  `var ErrNoMainWorktree = errors.New("ade: the repository's main worktree is missing")`.
  `ErrNoWorktree` loses its only caller, so delete it.
- `taskSession` returns `(*codeworkspace.Session, bool, error)`. The bool is `main`. When
  `worktree == ""`, resolve `mainWorktree` and open the session on it. Key the session by `sb.ID` as
  today. `Registry.Open` (`codeworkspace/session.go:64`) already replaces a session whose root
  changed, so a worktree created later takes over on the next call.
- `TaskFiles` returns a new `TaskFileListing{codeworkspace.FileListing; Root string; Main bool}`.
  `Root` is `sess.Root`. `TaskFileRead`, `TaskFilesSession` and `TaskFileTarget` drop the bool.
- Update the comments on `taskWorktree` and `taskSession`.

`internal/bridge/adetask_files.go:57` `TaskFiles` returns a new wire struct `AdeTaskFileListing`.
It has explicit fields, `Paths []string`, `Status map[string]string`, `Truncated bool`,
`Root string` and `Main bool`, with JSON names `paths`, `status`, `truncated`, `root` and `main`. Do
not embed a struct: keep the Wails binding shape flat. Regenerate bindings with
`wails3 task common:generate:bindings` (DEV_ENVIRONMENT).

`internal/bridge/adetask.go:126`: map
`{ade.ErrNoMainWorktree, ipcerr.CodeNotFound, "backend.space.ade.files.noMainWorktree.body"}`.

i18n (`packages/theme/src/i18n/en.json`):

  "The repository’s main worktree is missing."

### 3. Collapse change

- `AdeFileTree.vue:34-47`: delete the `initExpanded` watch and its comment. Nothing seeds expansion,
  so every folder starts collapsed (`AdeFileTree.vue:76` falls back to an empty set). The search
  filter still force-expands matching ancestors (`fileTreeModel.ts:96-97`); that is filter
  behaviour, not auto-expansion.
- `filesUi.ts`: delete `initExpanded` and remove it from the store's return. Change the `expanded`
  doc comment (:17) to "Per branch: expanded directories, set by the user's toggles; absent means
  all collapsed."
- Expansion a user sets is unchanged. The per-branch set lives for the window's life: it survives
  Refresh, a branch switch and back, and a listing refetch, because only the seeding goes. Nothing
  persisted it across a relaunch before this phase (memory store, ARCHITECTURE 1437), and nothing
  persists it after. No persisted state to migrate.
