## 1. Treatment rules

One rule per element role; every surface below maps to one.

| Role | Treatment | Ground | Text |
|---|---|---|---|
| Head of the owner's view (view head, task head, dialog header) | band | rest band; no hover | neutral |
| Tab of an owner | band | rest; hover band on hover; hover band when active; `bg-select` when multi-selected (P727 neutral) | muted idle, fg active |
| List row of an owner (and every row in its tree group) | band | rest; hover band on hover; selected: hover band plus 1px inset fg ring (P764 selected-row recipe on the band) | neutral |
| Inline reference to an owner inside another element (repo chip, env name, connection name, task name) | chip: `ColourChip` | rest band | fg |
| Picker of a colour (swatch picker, colour menus, environment and repo colour menus) | swatch (ink), unchanged | | |
| Engine or connection icon | ink icon, unchanged | | |
| `none` colour | nothing: neutral chrome, no band, no chip ground beyond today's neutral chip | | |
| Task status (chip, row text, glyph, editor dot) | status palette, unchanged from P766 | solid ink chip | chrome on chip, ink as text |

- No colour dots remain outside pickers. No 4px rails, 2x14 tab bars, 16x3 line marks or 2px band
  lines remain. `colorMarkClass` keeps only `swatch` (and `dot` for the env-select menu, see §2.3);
  `rail`, `bar`, `band`, `line`, `under` go with their last caller.
- `ColourChip.vue` (new, `packages/workbench/src/components/`, `<script setup lang="ts">`): wraps
  `Badge variant="chip"`; prop `hue: Hue | null`; `null` keeps `bg-field text-muted-foreground`
  (today's `none` chip); `grey` uses `bg-field text-fg` (grey's rest band equals
  `--kira-bg-elevated`, invisible on elevated grounds such as dialogs and tooltips); other hues
  `BAND text-fg` with `bandStyle(hue)`.
- Contrast: fg on rest band >= 11.16, on hover band >= 10.68, subtle on hover band >= 4.86 (`P764.md`
  numbers, guarded by `tests/unit/colour-palette.spec.ts`). Muted tab text on rest band: muted
  >= 6.43. Status text on any band >= 4.82 (P766 §2). No new pairing below 4.5.
- `ColourChip` (identity, faint band ground, fg text) and the status chip (solid saturated ink,
  chrome text) must stay visibly different where both sit in one row (plan card line 2, panel head,
  phone card): never restyle the status chip toward the band recipe.
