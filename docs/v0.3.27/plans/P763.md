### Main vs related today

`linkGroups.ts` already splits:

- `own` (`isOwn`, 103-107): Jira and host slots, detected (`id === ''`) change requests and issues,
  stored rows whose URL is a board change request of the task's own branches (`ownUrls`,

- `others`: every other stored row (user paste, agent report).
- `branches`: detected branches, only with `opts.branches` (stage dialog Done move). Details hides
  them.

Code wording calls every non-found link "main" (`promote` comment, `useTaskLinks.ts:93`). Owner's
tiers differ: a pasted link is related. Rule in §2 follows owner and `isOwn`, not that comment.

## 2. Tier rule

Computed in `linkGroups.ts` from wire data alone (grouping, not recognition).

**Main**, first match:

1. Jira slot (`task.jira`).
2. Host slot (`task.hostUrl`).
3. Detected row: `id === ''` and `source !== 'notes'`. Covers host change requests, tracker issues,
   git branches, deployments.
4. Stored row whose normalized URL is in `ownUrls`.

**Related**: every other row. Stored user and agent rows, and found links (`source === 'notes'`).

Consequences:

- First pasted Jira link or PR fills its empty slot (`fileLinkLocked`, `links.go:93-106`), so it
  becomes main without new state. Later ones are related.
- Detected branches and deployments move from "only on a Done move" to main in every mount (Q4).
- Dashed outline goes: detected rows are now main, so "dashed = detected" stops holding. Found rows
  keep the note icon.
- No user "mark as main" control: it needs a stored flag (schema change). Out of scope (Q5).

Order inside a tier: kind order issue, change request, branch, deployment, doc, link (existing
`artifactKindOrder` order); found links last in related; input order inside each kind. Categories
(Issues, Change requests, Misc, Related) and the category icon column go; kind icon on every row
carries kind.

## 3. Face per link: host, primary, secondary

Computed in backend, one function, so recognition stays next to `linkclassify.go`. Wire field `face`
(§5).

### Host column

First match:

1. URL http(s) and `Registry.ParseBranchLink` claims it: `host` = `Repo.Host` lowercased,
   `hostRepo` = `Owner/Name` (provider case), `hostKind` = `code`.
2. URL http(s): `host` = hostname lowercased, leading `www.` dropped, port kept when not default,
   punycode kept (lookalike guard: host is the "where does this click go" cue). `hostKind` = `web`.
3. No URL, `Repo` set (local branch, deployment): `host` = nickname, `hostKind` = `repo` (drawn with
   repo icon, UI font, never reads as hostname).
4. No URL, Jira key (`ParseJiraRef` matches `Ref`): `host` = '', `hostKind` = `jira` (frontend
   renders i18n "Jira").
5. Else: all ''.

`rest` (internal, feeds primary/secondary): URL minus scheme, minus `host` (and `hostRepo` for code),
fragment dropped, query kept, leading and trailing `/` trimmed.

### Primary and secondary

`primaryStyle`: `title` (UI font, `fg`), `ident` (data font), `path` (data font, muted). Titled check
`titled(a)` = `Title != ""` and `Title != pastedArtifactTitle(URL)` and `Title != Ref` and
`Title != URL`. Extract it as one helper and reuse it in `editStoredLocked` (replaces line 267).

First match:

| Case | `primary` | `primaryStyle` | `secondary` |
|---|---|---|---|
| Branch | `Title` (branch name) | `ident` | '' (frontend shows status label when URL empty: `local`) |
| Deployment | `Title` (env) | `title` | `Ref` (short sha) |
| Titled | `Title` | `title` | `Ref`, else `rest` |
| Untitled, `Ref` set (Jira key, `#77`, `!9`, tree path) | `Ref` | `ident` | '' |
| Untitled, URL | `rest`, `/` when empty | `path` | '' |
| Else | `Title`, else URL | `path` | '' |

## 4. Design

Mockup: `P763-mockup.html` (today, B1, B2; same 17-link task, 12 untitled, 6 main, 11 related).

### Common to B1 and B2

- One 22px row per link (`h-[22px]`, today's pill line is 24px). Grid on the list with `subgrid`
  rows, so the host column aligns across rows: kind icon 14px, host `fit-content(38%)` (B2: 36%),
  name `minmax(0,1fr)`, status dot 8px, `gap-x-2`.
- Main rows: text `text-fg`, host `text-subtle`. Related rows: text `text-muted-foreground`, host at
  75% opacity, kind icon `text-subtle`. Main and related share columns, so the host column stays one
  line down the list.
- Related header: a full-width row below main, `border-t border-border`, chevron, "Related", count.
  shadcn-vue `Collapsible` (already used by the strip). Open state per viewer via VueUse `useStorage`
  (`ade.links.related`), default open in Details, folded in stage and run dialogs. Folded header
  shows a host peek (distinct related hosts, data font, ellipsis).
- Related shows 3 rows then "N more" (existing `common.more.label`). Main never collapses (it is
  the task's own: rarely over 6).
- Same host as the row above, same tier: host at 45% opacity (scan aid, Q6).
- Truncation: secondary shrinks to nothing first, then name (min 6ch), then hostname part, then
  `hostRepo` part (code hosts keep `acme/api` readable longest). End ellipsis everywhere.
  `TruncatedText` tooltips a truncated name; row `title`-style tooltip (`TextTooltip`) shows full URL
  for every row with one.
- Hover: tooltip with full URL (data font). Card (existing Popover, right-click/Space/Alt+Down)
  gains a host line (`host` + `hostRepo` + ref) under the title; untitled stored row in edit mode
  shows hint "No title. Edit to add one" with `title url` sample; meta row adds "Related" for
  related rows.
- Keyboard: one tab stop, `RovingFocusGroup orientation="vertical"`. Up/Down rows (across tiers and
  the Related header), Home/End, Enter open (no URL: card), Space/Alt+Down card, F2 edit, Delete
  remove, `+` add, paste on a row adds. Related header: Enter/Space toggle, Right expand, Left
  collapse. "N more": Enter expands, focus to first new row. Line-jump branch in `onKeydown`
  (`AdeLinkStrip.vue:151-160`) goes.
- Empty, loading, gaps, error states unchanged.
- Height (17 links): today 4 pill lines about 120px; B1 default about 270px; related folded about
  180px. Typical task (2 main, 1 related): 70px today, about 120px. Details tab scrolls as one
  (`AdeDetailsTab.vue:31`), so the task chain below moves down by that amount.
- Colour: only existing tokens. No favicons (CSP `img-src 'self' data:`; fetching leaks every
  linked host). No provider glyphs unless owner asks (Q3).

### B1: host first (recommended)

Columns: kind, host, name + secondary, dot. An untitled row reads as its URL split at the host
(`acme.atlassian.net  wiki/spaces/PAY/…`), so related rows, mostly untitled, never read as
fragments. Host column is the identity anchor: equal hosts stack, so "which links go to Jira" is one
glance.

### B2: name first, host right (alternative)

Columns: kind, name + secondary, host right-aligned, dot. Titled main links scan by meaning first.
Untitled rows read reversed (path left, host right) and the path, not the host, leads.

### Recommendation

B1. Most rows are untitled, and for them the host is the most meaningful word. B1 puts it first and
aligned; B2 leads with the weakest text.

### Wire contract

Additive keys, contract change per P143 rule 1 (`wire.go` / `wire.ts` header).

```go
// LinkFace is how a link row reads: host column, name and secondary text.
type LinkFace struct {
	Host         string `json:"host"`         // '' none
	HostRepo     string `json:"hostRepo"`     // owner/name on a code host; '' otherwise
	HostKind     string `json:"hostKind"`     // web | code | repo | jira | ''
	Primary      string `json:"primary"`
	PrimaryStyle string `json:"primaryStyle"` // title | ident | path
	Secondary    string `json:"secondary"`    // '' none
```
