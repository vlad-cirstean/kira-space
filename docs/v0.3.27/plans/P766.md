# P766: One colour module

Owner request: unify colour components so a later colour change is one edit. One module owns palette,
band, mark and selection ring; every coloured surface consumes it.

Owner decisions (`SPEC.md` P766, audit `colour-audit.md` §5, mockup `colour-rollout-mockup.html`),
binding:

- One palette app-wide: the task Pure-B inks and bands (`P764.md` §2) serve tasks, connections,
  environments, repos, scripts, terminals and task statuses.
- Legacy names: add `lime` and `sky` as stored names; stored `olive`, `cyan`, `indigo` display as
  `lime`, `sky`, `blue`.
- Task status uses the same palette for now.
- Engine and connection icons stay as they are (P767 must not neutralise them; P766 keeps engine kind
  colours at today's values).
- Band only, no dots in heads; tabs and list rows take the band; repo chips: band ground, neutral text.
  These are P767's rollout. P766 builds the pieces they need and changes no treatment.

Scope of P766: one source per colour fact, frontend and Go. Visible change is limited to the new inks
(identity marks repaint in Pure-B) and status chips moving to Pure-B. Rails, bars, dots, lines, chips
keep their shape. Discovery: `codegraph_explore` on `connColor.ts` (blast radius: 30 `colorMarkClass`
callers in 15 views, 10 `connIconClass`, 5 `connColorVar`), `ViewHead`, `TabStrip`, `ColorLine`,
`StatusDot`, `palette.go`, `ValidPaletteColor`, `AdeStatusColors`, `statusColors.ts`, `repoTint`,
`repoText`, `taskColor`, plus grep for exact lines and for token consumers codegraph does not index
(CSS, Astro, specs).

Frontend paths below are under `apps/kira-space/frontend/src/` unless rooted. Go paths are under
`apps/kira-space/internal/` unless rooted.

### `packages/theme/src/colour.ts` (replaces `connColor.ts`, `ade/v2/palette.ts`, `ade/v2/statusColors.ts`)

```ts
export const TASK_HUES = ['red','teal','amber','violet','blue','orange','magenta','green','lime','sky'] as const;
export type Hue = (typeof TASK_HUES)[number] | 'grey';
/** Picker order, chromatic hues by hue angle, grey last. */
export const PICKER_HUES: readonly Hue[] = ['red','orange','amber','lime','green','teal','sky','blue','violet','magenta','grey'];

export function hueOfSlot(slot: number): Hue;            // TASK_HUES[slot mod 10]
export function hueOfName(name: string | null | undefined): Hue | null;
// 'none', '', null, unknown -> null; olive -> lime, cyan -> sky, indigo -> blue; else the name.

export function inkVar(hue: Hue): string;                 // 'var(--kira-hue-red)'
export function bandStyle(hue: Hue | null): Record<string, string> | undefined;
// { '--band': 'var(--kira-hue-red-band)', '--band-hover': 'var(--kira-hue-red-band-hover)' }

export const BAND = 'bg-(--band)';
export const BAND_INTERACTIVE = 'bg-(--band) hover:bg-(--band-hover)';
export const BAND_ACTIVE = 'bg-(--band-hover)';

// Literal class maps (Tailwind scans literals): Record<Hue, string>
export const HUE_BG, HUE_TEXT, HUE_SWATCH, HUE_CHIP;     // HUE_CHIP: 'bg-hue-x/15 text-hue-x'

export type ColorMark = 'rail' | 'bar' | 'dot' | 'band' | 'swatch' | 'line' | 'under';
export function colorMarkClass(mark: ColorMark, color: Hue | string | null | undefined): string;
// resolves through hueOfName; same "no colour" rule as today (empty slot, ring for dot/swatch).

export const SELECTION_RING;   // from taskGrid TASK_EDGE_SELECTED (1.5px fg outline, inset)
export const SELECTION_ROW;    // from taskGrid GROUND_SELECTED
export const SWATCH_RING;      // SwatchPicker:48 'outline-2 outline-offset-2 outline-fg'

export function colourLabel(color: OfferedColor): string; // moved unchanged
```

- `colorMarkClass` keeps its name (guards and `ARCHITECTURE.md` cite it). New shapes `line`
  (`inline-block h-0.75 w-4 shrink-0 rounded-full`) and `under`
  (`pointer-events-none absolute inset-x-0 bottom-0 h-0.75`) absorb `ColorLine.vue`; `edge` is not
  carried if P764 left no caller (grep `variant="edge"`).
- `connIconClass` survives as `inkTextClass(color)` (= `HUE_TEXT[hue] ?? 'text-muted-foreground'`),
  same behaviour: engine icons in heads keep the connection ink (owner decision).
- No hex in `colour.ts`: every value is a `var(--kira-hue-*)` reference or a class. Specs and the unit
  guard read hex from `tokens.css`.
- `hueOfName` is the only legacy mapping. `PICKER_HUES` is the order every picker uses.
