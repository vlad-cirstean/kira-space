## Reading of the ask

Edit dialog = `ConnectionFileDialog.vue` and its tabs under `apps/kira-space/frontend/src/studio/project/connection/`. Catalog today: 90 explanatory strings (body, description, hint, note label), about 1,870 words. The MCP tab alone renders up to about 1,100 words with MCP on.

Three problems:

1. Length. Single paragraphs of 40 to 76 words (`throttle.description` 69, `enforceMasking` 76, `maskedEnforceHit` 59, `autoExplain.description` 51).
2. Same text rendered twice. `throttle.description` shows on Advanced and again on MCP. `mcp.enforceMasking.body` shows on Privacy and again on MCP. `studio.settings.advanced.expensiveRows.description` (Settings text) shows again on MCP.
3. Same idea repeated per control. "The agent may ask for an exemption; you always approve it in a dialog" sits in `rowsHit`, `timeoutHit`, `maskedEnforceHit` and `enforceExemption`. "Kira enforces this, not the database" opens `rowsWho`, `maskedEnforceWho`, `reviewEnforceWho`, `privacy.reviewEnforceWho`. "Unclassifiable statement counts as strictest" sits in both `enforceDdl` and `strictest.description`. "A write has already run" sits in `review.description` and `reviewEnforceLimits`. Deny and Allow are spelled out under buttons already labelled Deny and Allow.

Edge-case detail cut here (semicolon filters, side-by-side throttle, approval-prompt review, held-result mode inference) is already in `site/src/content/docs/docs/studio/database-mcp.mdx` (sections Permissions, Masked browse, Column review, Approvals). Site docs quote labels only, and labels do not change, so no site edit.

Security caveats stay, compressed, in plain words: preconnect warning, read-only lane leak, masking best effort, key fallback, withhold does not undo a write. CLAUDE.md exempts security warnings from terseness.

## Decisions

- **D1 One home per idea.** Exemption rules live only in `mcp.enforceExemption.body`. Throttle detail lives only on Advanced; MCP keeps its own one-line lead. Masking enforcement lives only on Privacy. Row threshold meaning lives only in Settings; MCP names the number.
- **D2 Keys.** Rewrite values in place; keep keys so call sites stay. Delete a key only when nothing renders it: `mcp.tablesEnforceFail.body` (folded into `tablesEnforceParse`). Keys that stop rendering on MCP but still render elsewhere stay (`throttle.description`, `mcp.enforceMasking.body`, `studio.settings.advanced.expensiveRows.description`).
- **D3 Catalog rules.** Every new value passes `scripts/copy/catalogRules.ts`: body, description and hint end with `.`; note labels have no period and start uppercase (C6, C7). No two keys share a text (C3, C4). Curly quotes and `’` (C5). `bun scripts/copy/check-catalog.ts --unused` clean.
- **D4 Tests.** Specs that assert a sentence this plan removes or rewrites get updated to the new essential phrase. Assertions for removed paragraphs move to where the idea now lives. No assertion is dropped without its meaning being asserted somewhere.
