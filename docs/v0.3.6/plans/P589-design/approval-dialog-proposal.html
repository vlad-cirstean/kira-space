Anatomy

  1. Line 1, left: operation (13px semibold, tone colour) · target (13px semibold) · where (12px muted) · risk tags (icon + 1-4 words).
  2. Line 1, right: countdown only (11px subtle).
  3. Colour rule: colorMarkClass('band', color), 2px, full item width, under line 1. Drawn only when target.color is set: DB connections and API environments today (shop db, analytics, api). notes db, kube, script, branch, task and proof carry no colour, so nothing is drawn.
  4. Content: SQL, path + query + body, result rows, command, diff, branch rows, brief. Unboxed, indented 12px, data font.
  5. Details: label 72px (11px subtle), value 12px. Lists over 3 rows collapse to "+N more".
  6. Footer: requester (11px subtle), option, Deny, Approve.
  7. No cards, no fills, no sentences. One hairline between items.
