## Decisions

1. One new component `details/AdeLinkOpenExternal.vue`, mirroring `AdeOriginSession.vue`: prop `url`;
   renders nothing when `url` is ''; else shadcn-based `TooltipIconButton` icon `link-external`, label
   `t('space.ade.details.openExternal.tooltip')`, `class="shrink-0"`, testid `ade-details-open`, click
   `fireAndForget(control.openExternal(props.url), 'ade.details')`. Same call the title click makes; no
   raw URL to `window.open` or any browser API; no new bridge method. `<script setup lang="ts">`, Tailwind
   only, no store (no shared state), no query (fire-and-forget command, existing pattern in this folder).
2. `AdeDetailsLink.vue`: render `<AdeLinkOpenExternal :url="item.url" />` first in the `#actions`
   template, before `<slot name="trailing" />`. Shown for every origin and kind, read-only and archived
   included (opening changes nothing); hidden while editing (actions slot already hidden then).
3. Change requests: title click keeps the in-app host view (P74 behavior, `ade-v2-panel.spec.ts:587`
   stays green); the new button opens the same URL in the system browser through `LinkService`, not
   `GitHostService.OpenChangeRequestURL` (that one accepts GitHub pull URLs only; forge and Azure URLs in
   the Details tab must open too).
4. `AdeTimelineEntry.vue`: add `<AdeLinkOpenExternal :url="event.url" />` first in its `#actions`
   template, before `AdeOriginSession`. Branch and created events have url '' so no button.
5. Out of scope, stated in Result: handover and note prose links (inline rich text, not link lines; keep
   Cmd/Ctrl-click) and `AdeTaskIssueLine` (no URL of its own; the Jira row above carries the button).
   Orchestrator: this is the planner's reading of "each link" as each link row, matching the SPEC
   Context "Jira and other link lines"; confirm with the user if wider is wanted.
6. No backend change. The Go half proves the IPC contract: the URLs the Details tab lists (board task
   Jira and host fields, `Artifacts` rows) are accepted by `LinkService.OpenExternal` and reach the
   browser unchanged.
