rows, Studio grid cells and rows, trees, lists, nav, choice chips, radio cards, date cells, Monaco

something other than selection (§3.3). One token set is the source; a lint (N18) keeps selection
neutral.

moves lines in its files (§2.4). Re-read each file before editing.
