## 3. Design spec

### 3.1 Column model

Fixed tracks, same at every width; only the text column flexes. Right edges anchor: the head's
action slot and the branch row's tag slot are both `w-control` at the card's right padding, so they
form one column down the whole list.

Card head (inside `px-2`, `gap-1.5` between cells):

```
line 1 | lead w-6 | title flex-1 (relative; hover overlay at its end) | status w-20 | action w-control |
line 2 | (lead)   | step w-24 @lg:w-32 | meta flex-1 | flags shrink-0     | est w-20    | w-control       |
```

Branch row (inside `px-2`, after the existing depth indent span):

```
| repo w-20 | name + base + context flex-1 (relative; hover overlay at its end) | extras auto | PR w-control | tag w-control |
|           | line 2: progress … chips (col-start-2, spans to the end)                                          |
```

Span and history rows in a band reuse the head's lead and status widths so their titles start at
the card-title x.

### 3.2 Shared constants, new file `plan/taskGrid.ts`

Pattern as `panel/adeRow.ts`: class strings only, no logic.

```ts
// Plan task list column tracks: every card head, branch row, span and history row shares them, so
// columns line up whatever the content. Widths go on wrapper cells, never on shared components.
export const TASK_LEAD = 'inline-flex w-6 shrink-0 justify-center';
export const TASK_STATUS_CELL = 'flex w-20 shrink-0 min-w-0 items-center overflow-hidden';
export const TASK_ACTION_CELL = 'flex w-control shrink-0 items-center justify-center';
export const TASK_STEP_CELL = 'flex w-24 shrink-0 min-w-0 items-center gap-1 @lg:w-32';
export const BRANCH_GRID =
  'grid min-w-0 flex-1 grid-cols-[--spacing(20)_minmax(0,1fr)_auto_var(--spacing-control)_var(--spacing-control)] items-center gap-x-1.5 gap-y-0.5';
export const SLOT = 'flex w-control shrink-0 items-center justify-center';
/** Row ground for a hover overlay: the card sets it, a hovered or selected row overrides it. */
export const GROUND_CARD = '[--row-ground:var(--color-elevated)]';
export const GROUND_PARKED = '[--row-ground:var(--color-chrome)]';
export const GROUND_ROW = 'bg-(--row-ground) hover:[--row-ground:var(--color-field)]';
export const GROUND_SELECTED = 'bg-(--row-ground) [--row-ground:var(--color-select)]';
/** Hover actions laid over the end of the text cell: no reflow when they appear. */
export const HOVER_OVERLAY =
  'absolute inset-y-0 right-0 items-center gap-0.5 pl-4 bg-linear-to-r from-transparent via-(--row-ground) via-35% to-(--row-ground)';
```

If this Tailwind version rejects `--spacing(20)` inside an arbitrary value, use
`calc(var(--spacing)*20)`. Confirm with `bun run build:test` and a computed-style check
(`grid-template-columns` starts `80px`).
