# P711: command palette holds only what has no other entry point; every removed action has a shortcut

## 1. Goal

Palette today lists 27 commands, nearly all one click away. Remove every command with another
visible entry point; give each removed action a keyboard shortcut in `SHORTCUTS`
(`packages/shared/domain/shortcuts.ts`). Module-contextual actions (New, New alternate, Import)
share one chord each; effect follows active module. Palette stays (⇧⌘P), with the rest.

Base: chapter branch after P710 lands. Line refs below are the chapter tree at `15a885894`.
Re-read each file before editing. CodeGraph index is older (v0.3.17); every ref here was re-read in
the worktree.

## 2. Facts the design rests on

- macOS is the only target (`docs/ARCHITECTURE.md:31`). Linux runs only dev and CI.
- Global chords are Go native menu accelerators. `internal/shell/accel.go:39-56` mirrors the TS
  globals; `apps/kira-space/internal/appshell/menu.go:18-70` builds items with
  `shell.Shortcuts[id].Accelerator()`; each emits a channel; `App.vue:148-188` subscribes. Rule in
  `useShortcut.ts:18-19`: "Global chords stay Go menu accelerators plus `registerCommand`".
- Local chords use `useShortcut(target, ids, handler, opts)` (`packages/workbench/src/shortcuts/useShortcut.ts:20`);
  `capture: true` beats Monaco. `form.save` is already bound this way in `HttpRequestView.vue:281`
  and `GrpcRequestView.vue:253`.
- `registerCommand`/`runCommand` (`packages/workbench/src/shortcuts/commands.ts`) is a mount-scoped
  registry. Left panel is `v-if="projectVisible"` (`packages/workbench/src/components/WorkbenchShell.vue:68`):
  a hidden panel registers nothing. So a module action cannot rely on panel registration.
- No user rebinding exists. `SHORTCUTS` is a `const` table; "rebindable" today means one row in
  `shortcuts.ts` (plus `accel.go` for a global). See §10 Q1.
- Existing conflict guard: `packages/workbench/src/shortcuts/shortcutsConflicts.spec.ts` (no
  duplicate chord inside a scope or against `global`, both platforms). No TS/Go parity check, no
  reserved-chord check. `accel.go:5` comment says "13 `global: true` bindings": stale.
- Only the palette calls `runCommand` for `api.save`, `api.copyAsCurl`, `api.editRaw`, `api.import`,
  `api.environments`, `view.explain`, `data.generate`, `data.filterColumns` (grep: other
  `runCommand('` callers are `App.vue:168,183-186` only). Those registrations go dead once the
  palette drops them.
- UI specs cannot press a native accelerator; they emit the menu channel (`emitWailsEvent(page,
  IPC.commandPalette, …)`, `consistency.spec.ts:71`). Go half asserts item carries accelerator and
  channel (`appshell/menu_test.go:12`).

## 3. Decision rule

Remove a command when it has a control visible in the module's normal working state (title bar,
panel header, view toolbar, tab-strip "+" menu, visible field) or a menu-bar item. Keep it when its
only other path is a right-click menu or a button on an empty start screen only.
