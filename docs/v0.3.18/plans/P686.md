## 2. Conventions every scenario follows

- One scenario = one flow test (asserts the result) + one UI spec on the mock bridge reading the same
  contract (asserts the same result as the user sees it). Flow header comment names its UI half; UI header
  names its backend half (as in `approvals-api-input.spec.ts`).
- Files: flow `apps/kira-space/internal/flows/dbmcpflow/e2e_<topic>_test.go`, test `TestE2E<Topic>`
  (subtests per step group); contract `apps/kira-space/tests/contract/e2e-<topic>.json`; UI spec
  `apps/kira-space/tests/ui/studio/e2e-<topic>.spec.ts`.
- Contract keys: `<Service.Method>#<step>` (e.g. `ApprovalsService.List#step2`,
  `DbMcpService.PendingResponse#review`, `KeptVarsService.List#scopes`, `OpsService.Recent#failures`),
  `args:<Service.Method>#<step>` for calls the UI must make, `result#<step>` for agent texts. Record with
  `KIRA_CONTRACT=write`, rerun without it, both green.
- Normalise: `flowharness.Mask("createdAt", "expiresAt", "cwd", "environment.id", "expiresInSeconds")`,
  `Replace(srv.URL, "http://127.0.0.1:<port>")`, `Replace(f.dbPath, "/data/mcp.db")`, `Replace(meta.ID,
  "kv_<name>")` (suffix `_2` for a replaced entry), `stable()` (`api_review_test.go`) on every response text
  stored. UI rewrites kept times to live values (`storedItem()` pattern) and wraps items with `liveItem`.
- Mock IPC matches exact args (`canonical`): every Answer, Clear, ClearAll, Settings.Set, Reveal asserted
  with `expect.poll(() => control.log().find(...)?.args).toEqual(contract('args:...'))`.
- Never `t.Parallel()` in dbmcpflow (shared containers, global slog capture).
- Unit-test bar: no new unit tests. Scenarios are flow + UI. Adapter probe additions are conformance (exempt).
  A bug fix whose logic is genuinely complex (none expected) may earn one; name the reason in the commit.

### Leak oracle (Wave 0, `e2e_helpers_test.go`)

`f.noLeak(t, value string, agentTexts ...string)` fails when any form of value appears in:
agent results passed in; `Ops.Recent{Limit: 500}` JSON; captured slog (`captureLog(t)` sets
`slog.SetDefault` to a Debug JSON handler over a buffer, restored in Cleanup; precedent
`configflow/secretref_test.go`); every emitted event (`f.app.Events.Since(0, "")`); `ApprovalsSvc` list after
the answer; prompt router entries (the `W.Prompts` read used by `prompts_test.go`); `ListTools` names,
descriptions, schemas; `KeptVars.List`; every file under `f.app.SpaceHome` (SQLite, `-wal`, `-shm`, config,
logs) read as bytes. Forms computed in the test, independent of `keptvars/forms.go`: raw, JSON-escaped,
`url.QueryEscape`, `url.PathEscape`, base64 std, base64 raw-URL. The disk scan skips nothing.

### UI leak helper (Wave 0, `tests/ui/studio/support/e2eLeak.ts`)

`expectNoLeak(page, value, logs)`: `body` text, every `input` value, `localStorage` and `sessionStorage`
JSON, console lines. Used after every answer that carried a typed value.
