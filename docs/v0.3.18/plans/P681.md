### Remove 2: `shell-quote` (duplicate of `shlex`)

Two POSIX shell lexers: `shlex@3.0.0` (api-core curl import/generate; ARCHITECTURE records why it
won: continuations, empty args, ANSI-C `$'…'`, literal `$VAR`, `{{token}}`) and `shell-quote@1.12.0`
(frontend `credentialPaste/parse.ts`, one call in `tokenize`). Keep `shlex` (MIT, 3.0.1 released
2026-11-18, already in the tree; no new package enters `bun.lock`).

- `apps/kira-space/frontend/package.json`: replace `"shell-quote": "1.12.0"` with
  `"shlex": "3.0.0"` (same pin as api-core, so one install; knip needs the frontend to declare it).
- `credentialPaste/parse.ts` `tokenize`, before the swap: run the current spec plus the three new
  cases below on the shell-quote version and record outputs; the shlex version must match them.
- New `tokenize` shape:

```ts
import { split } from 'shlex';

// Bare operators end the command; shlex splits words only, so a quoted `;` stays inside its word.
const SHELL_OPERATORS = new Set(['|', '||', '&', '&&', ';', '>', '>>', '<', '#']);

/** shlex throws on an unterminated quote; shell-quote read it to end of line. Keep that. */
function splitLenient(text: string): string[] {
  for (const tail of ['', "'", '"']) {
    try {
      return split(text + tail);
    } catch {
      // try the next closing quote
    }
  }
  return [];
}

function tokenize(text: string): string[] {
  const argv = splitLenient(text);
  const stop = argv.findIndex((t) => SHELL_OPERATORS.has(t));
  return stop === -1 ? argv : argv.slice(0, stop);
}
```

  shlex never expands `$NAME`, so the env callback goes away with the same result (literal
  `$NAME`). Glob patterns already came back as text. Known delta, accepted: an operator glued to a
  word (`-h host;`) stays part of the word, as in curl import.
- `apps/kira-space/tests/unit/studio/credential-paste.spec.ts`: add three table rows (parser with
  interacting rules, unit-test bar met): CLI line cut at a bare `|`
  (`psql -h h -U u | tee log`), literal `$PGPASSWORD` value kept, unterminated quote read to end
  (`mysql -u u -p'pa ss`). Expected values are the shell-quote outputs recorded above.
- ARCHITECTURE line on shlex (curl tokenizing bullet): append `; credential paste
  (credentialPaste/parse.ts) uses the same split`. No other doc names `shell-quote`. NOTICES does
  not list either package.

### Conditional remove 3: `@astrojs/markdown-remark` in `site/package.json`

Zero imports. It is an optional peer of `astro`, `@astrojs/starlight` and `@astrojs/mdx`, needed
only when `markdown.processor` gets `unified()` from it; `site/astro.config.*` sets no markdown
processor. Astro's `.d.ts` files import its types, so removal can change `astro check`.

Proof, in order: `cd site && bun run build`, copy `site/dist` to the scratchpad; remove the dep,
`bun install`, `bun run typecheck:site`, `bun run site:build`; `diff -r` old and new dist.
Remove only if typecheck passes and dist is byte-identical (ignore nothing). Otherwise restore it,
add one line to `docs/ARCHITECTURE.md` site section naming why it stays (optional peer the build
or `astro check` needs), and record the observed failure in the phase Result.
