### How a validity error stays visible without the path row

- Form dialogs (`RepoFilePane`, `RunFileDialog`, `ConnectionFileDialog`, `ApiVariablesDialog`)
  decode the draft through `useConfigFormDraft` (`packages/workbench/src/config/useConfigFormDraft.ts:68-83`).
  A clean draft equals the disk text, so a schema problem on disk usually also lands in
  `draft.problem` and shows as the existing form problem Alert (`unclaimed`, or `draft.problem` in
  RunFileDialog `:294-311`) or a field error with a tab badge. A loader-only problem (e.g. a bad
  Run script reference, `ade-v2-repo-script.spec.ts:114-138`) never reaches `draft.problem`: today
  only the bar shows it.
- Workflow and step editors have no draft problem: `entry.error` shows only in the bar.
- New `packages/workbench/src/config/ConfigFileProblem.vue` on every non-YAML tab: shadcn-vue
  `Alert variant="error"` with the file's problem and a Show in YAML action. It renders nothing
  when the file is valid, and nothing when the tab already shows the same problem (`shown` prop,
  equal line and message), so one problem never shows twice and two different problems both show.
- Text reuses existing catalog keys: `common.configForm.problem.status` ("Line {line}: {message}")
  when `line > 0`, else the message alone; action `common.configForm.showYaml.label`. No new
  catalog key.

### 1. `feat(ade): config file bar only in YAML mode of workflow and step editors`

New component `packages/workbench/src/config/ConfigFileProblem.vue` (`<script setup lang="ts">`):

```ts
// A config file's problem on a tab without the file bar (P578). Nothing when the file is valid or
// the tab already shows this same problem.
type Problem = { line: number; message: string };
const props = defineProps<{
  error?: Problem | null;
  /** The problem the tab already shows, if any. */
  shown?: Problem | null;
  /** Switches to the YAML tab; omitted hides the action. */
  showYaml?: () => void;
}>();
const visible = computed(() => {
  const e = props.error;
  if (!e) return null;
  const s = props.shown;
  return s && s.line === e.line && s.message === e.message ? null : e;
});
```

`AlertDescription` with `visible.line > 0 ? t('common.configForm.problem.status', { line, message })
: visible.message`, and `AlertAction v-if="props.showYaml"` holding
`Button variant="link" size="inline" data-testid="config-file-problem-show-yaml"` labelled
`t('common.configForm.showYaml.label')`. Imports as in `RepoFilePane.vue:3-5`.
