# P579 Darker dialog surface

Base: `chapter/v0.3.5` at `f9edf54fe` (P578 implemented). One sequential Sonnet implementer.
Renderer only: one token pair, one frame constant, three dialog components, one UI spec, docs,
visual baselines. No streams.

## Pick

Dialog-only surface token `--kira-bg-dialog: #141416`, plus darker scrim `--kira-scrim: rgb(0 0 0 /
0.6)` (was 0.4). Popovers, menus and toasts keep `bg-elevated`.

Why:

- Lowering `--kira-bg-elevated` globally is out. It is in 35 renderer files plus Monaco widget
  colours (`packages/workbench/src/editor/monacoTheme.ts:163-233`), SlickGrid head and cells
  (`apps/kira-space/frontend/src/studio/views/shared/slick/slickTheme.css:52,141,336`), chart
  tooltips (`apps/kira-space/frontend/src/studio/charts/theme.ts:34`), ADE day band stripes. It is
  the "raised" rung (cards, table head, active tab). Going below `--kira-bg` (`#1b1b1e`) inverts
  the ladder everywhere; staying above it cannot reach "blacker".
- Darker scrim alone leaves the dialog `#212125`, the pale grey the user names.
- Dialog-only token changes exactly the surface asked about. Elevated content inside a dialog
  (active tab, card, table head) then reads raised above it, which matches the ladder.
- `#141416` sits one step above `--kira-bg-chrome` (`#131315`), neutral zinc hue like the rest.
  Scrim 0.6 drops the dimmed app behind it to `#0b0b0c` (from `#1b1b1e`), so the dialog still lifts
  off its backdrop. At scrim 0.4 the backdrop would be `#101012`, too close to `#141416`.
- One theme only: `tokens.css` has a single `:root` block, no light theme, no
  `prefers-color-scheme` or `data-theme` rule. Acceptance "both themes" does not apply.

User may overrule: exact hex, scrim strength, popovers and menus staying elevated.

  pass `class="bg-dialog"` from `CommandDialog`. `cn` merges it against `bg-elevated`
  (tailwind-merge treats `bg-<name>` as a bg colour); the spec below proves it.
- `bg-scrim` users: `DialogOverlay.vue:19`, `TextPromptDialog.vue:49`,
  `packages/git-ui/src/App.vue:1894` (side panel backdrop). All darken to 0.6; one meaning of scrim
  stays one value.
- Popover opened from inside a dialog stays `#212125`, so it reads raised over `#141416`. Fine.
- Only `packages/git-ui/src/components/dialogs/StackDialog.vue:201,230` paints `bg-bg` inside a
  dialog (inset lists). `#1b1b1e` on `#141416` reads as an inset well, like a field. Leave it.
- Monaco widgets inside `SchemaDialog` keep `--kira-bg-elevated`. Editor body is `--kira-bg`. Leave.
