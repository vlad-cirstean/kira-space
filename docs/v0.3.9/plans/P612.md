## Decisions

- D1 Seed the layout in the review shot only, through `prepare`: `review.shot.ts` relaunches with
  `{ ...STORY_LAUNCH, prepare }` where `prepare` awaits `STORY_LAUNCH.prepare(page)` then
  `page.addInitScript(() => localStorage.setItem('kira.repo.diffLayout', 'inline'))`. App default
  stays `sideBySide`. Not in `CAPTURE_LAUNCH`: `packages/workbench` is shared with no app keys, and
  only review shots show a diff. Not in `buildStory.ts`: keeps P613's shared support file untouched.
  Not a click on the toggle: a click leaves focus and hover state in the frame.
- D2 Guard the seed: before the first `shoot`, assert
  `.monaco-diff-editor` inside `repo-diff-editor` lacks class `side-by-side`, and
  `repo-diff-layout-inline` has `data-state="on"`. A renamed key then fails the shot, never ships a
  side-by-side image silently.
- D3 Landing title = h1 text exactly, derived so they cannot drift:
  `pageTitle: \`${HERO.line1} ${HERO.line2}\`` = `Everything agents need, in one place.`
  (trailing period kept: h1 text has it). No `Kira Space` suffix: the ask says same text.
  `og:title` follows (same prop). Description meta unchanged.
- D4 Final strings, every page:
  - `/` `<title>` and `og:title`: `Everything agents need, in one place.`
  - `/build/`: unchanged, `Build with Kira: plan, ask, branch, review, prove`.
  - `/404`: unchanged, `Not found`.
  - Docs (Starlight): unchanged, site name `Kira Space`, titles `<page> | Kira Space`. It is the
    brand label in the docs header, not the landing title; a tagline there reads wrong in every
    docs tab.
- D5 Copy matches the new image: shots.ts `build-review-window` alt becomes
  `Kira Space review window with the changed files, an inline diff of the CSV export and the review agent panel.`;
  build.ts review body `a side by side diff` becomes `an inline diff`.
