## Findings (checked against source, codegraph)

- Sizes hold: `--kira-row-height` 28px, `h-control` 22px (`--kira-h-sm`), `h-control-sm` 18px
  (`--kira-h-xs`). Today's Details links (`AdeLinkGroups`, one `AdeRow` per link, 96px label column,
  hover actions reserved, wrapping Jira row, always-on add row, one `Alert` per gap) cost about
  308px for eight links. Strip: 22 + 2 + 3 x 24 = about 96px at a 400px panel. At the 340px minimum
  panel a long Misc line can wrap once (about 120px).
- Callers (codegraph blast radius): `AdeLinkGroups` only in `details/AdeDetailsTab.vue`;
  `AdeDetailsTab` in `panel/AdeTaskPanel.vue` and `panel/AdeArchivedPanel.vue` (`readonly`,
  `@open-session="showSession"`). `AdeDetailsLink`, `AdeLinkAddLine` only in `AdeLinkGroups`.
  `AdeLinkKindMenu` only in `AdeDetailsLink`. `AdeDetailsLinkEdit` only in `AdeDetailsLink`.
  `linkGroups.ts` only in `AdeLinkGroups` and `AdeLinkKindMenu`. `AdeArtifactList` only in
  `stage/AdeStageDialog.vue`. `AdeLinkTarget` only in `AdeAddPopover.vue`.
- Shared, stay where they are: `details/AdeLinkOpenExternal.vue` (also `AdeTimelineEntry`),
  `details/AdeOriginSession.vue` (also audit, timeline, proof, note entries), `artifacts/gapText.ts`
  (also `hostview/IssueView.vue`, `CommentComposer.vue`, `AdeTaskIssueLine`), `artifacts/status.ts`,
  `panel/AdeTaskIssueLine.vue`.
- One dialog, four openers: `AdeStepMover` (step back/next/pick), task menu, Next stage/Finish
  actions and the routed `handover` popup (`AdeHandoverPrompt`) all open `AdeStageDialog` through
  `state/adeStageDialog.ts`; orchestrator pass is `store.mode === 'pass'` (`openPass`). So only
  `AdeStageDialog.vue` changes; `AdeStepMover.vue` and `AdeHandoverPrompt.vue` stay untouched.
  `store.card` is a `CardModel`, so `store.card.task` is the `Task` the strip needs.
- `AdeRunDialog` has `card.value.task`. It sets no `data-dialog-initial`, so reka focuses the first
  tabbable. A pill above the message would steal it: pin focus explicitly (below).
- `useTaskIssue(taskId, link)` has no `enabled`; it must not run for a task without Jira.
- No knip config entry names these files; `knip.json` needs no edit. No unit test covers
  `linkGroups`.
- Visual baselines: no `tests/visual` snapshot shows Details, the stage dialog or the Run dialog
  (`branch-panel-details.png` is `ade-branch-details`, the branch panel). Nothing to regenerate.
  New visual spec added (below). Site: shot `build-artifacts-list` captures
  `[data-testid="ade-details-links"]` (`site/src/data/shotCapture.ts`); shot flows in
  `tests/screenshots/build/branchesHandover.shot.ts` use old testids. Site visual baselines
  (`site/tests/visual.spec.ts-snapshots/build-*.png`) render shot captions as text.
- Mock runtime: `adeV2Control` defaults (`tests/ui/support/adeV2.ts`) answer `adeTaskArtifacts`
  (empty) and `adeTaskIssue` (no tracker), and `storyBoard` builds on them, so new strips in dialogs
  cause no `E_FIXTURE_MISS`.

### Design corrections

- `useTaskLinks(taskId, …)` cannot build groups from an id: Jira and host slots live on `Task`.
  Signature takes a `Task` getter.
- API drops `caption` and the `empty` slot: no caller passes either (every place uses "Links"
  and the default empty text). Adds `archived` (the session button opens differently there, as today).
- Gap line keeps today's full `gapText` sentences (contract strings, specs assert them) in one
  amber text block, not new short "Partial: …" wording.
- Add error and "already linked" show inside the add popover under its input, not under the header:
  that is where the input is.
- `+N` pill text reuses `common.more.label` ("{count} more"): copy coverage needs catalog text.
- Session button shows only in Details (edit) and archived Details; dialogs hide it (it would open
  the session behind the modal).

- Proof attach menu (`AdeProofAttachMenu`) and mobile unchanged.

## Final design

Folder `apps/kira-space/frontend/src/ade/v2/links/`. Tailwind utilities only, no `<style>`.
Every component `<script setup lang="ts">`. No Pinia store: open-card key and editing key are
component-local `ref`s in the strip (one strip, one concern, no cross-component state).

### `AdeLinkStrip.vue`

```ts
props: {
  task: Task;
  mode: 'edit' | 'view' | 'add'; // edit: Details; add: view plus + and paste (dialogs); view: read-only
  branches?: boolean;            // include detected branches in Misc (Done move)
  archived?: boolean;            // archived Details: session button emits instead of selecting
}
emits: { openSession: [sessionId: string] }
```

Shape, top to bottom:

1. Header line, `h-control` (22px): caption `t('space.ade.details.links.title')` left
   (`text-kira-sm text-muted-foreground`), `+` right (`TooltipIconButton icon="add"`, label
   `space.ade.details.addLine.aria`, testid `ade-links-add`; modes edit and add only). `+` is the
   `PopoverTrigger` of `AdeLinkAdd`.
2. Gap block (if gaps): one `text-kira-sm text-tone-amber` block `ade-links-gaps`, one
   `<span data-testid="ade-links-gap">` per gap with `gapText(g)`, joined by a space.
3. Error line (remove or recategorise failed): `text-kira-sm text-error`, testid `ade-links-error`,
   cleared on the next action.
4. `QueryState :query` (as today). Loading: one line of 3 `Skeleton` (`h-4.5 w-16 rounded-kira-sm`),
   line reserves `min-h-6`. Error: `QueryState`'s own error and Retry.
5. Empty (no item in any category): one `text-kira-sm text-muted-foreground` line `ade-links-empty`:
   `space.ade.details.empty.body` ("No links yet."), plus in edit and add modes
   `space.ade.links.empty.hint` ("Paste a link or press +.").
6. One line per non-empty category, order `LINK_CATEGORIES` (issue, changeRequest, misc):
   `<div data-testid="ade-links-line" :data-category class="flex min-h-6 items-start gap-1">`:
   - Lead: category icon 20px box (`flex size-5 h-6 items-center justify-center text-muted-foreground`),
     `CATEGORY_ICON[category]` 13px, wrapped in `Tooltip` naming category and count
     (`space.ade.links.category.tooltip`), testid `ade-links-category`, `aria-label` same text.
   - Pills: `flex min-w-0 flex-1 flex-wrap gap-1 py-[3px]`.
   - More than 8 pills: first 7, then a `+N` pill (`ade-links-more`, text `common.more.label`
     with `count`) as `CollapsibleTrigger as-child`; the rest in `CollapsibleContent class="contents"`
     (shadcn `Collapsible`, one per line, local `open` ref).

Root: `<div data-testid="ade-links" :data-mode="mode" class="flex flex-col gap-0.5">`. The pill
area is one reka `RovingFocusGroup` (`orientation="horizontal"`, `loop`), each pill a
`RovingFocusItem as-child`: one tab stop for all pills.

Strip-level listeners (VueUse): `useEventListener(root, 'paste', …)` files clipboard lines when a
pill or the root has focus and mode is edit or add (same `submit` as the add input, below).
`onKeyStroke` on root for `+` (opens add popover; edit and add), Up/Down (focus first pill of
previous/next line). F2/Delete/Enter/Space/Alt+Down are pill keydown handlers (keyboard map).

### `AdeLinkCard.vue`

Content of a shadcn `PopoverContent` (`w-80`, `align="start"`, testid `ade-links-card`). Props
`{ task: Task; item: LinkItem; mode; archived?: boolean; editing: boolean; links: TaskLinks }`
(the `useTaskLinks` result); emits `edit`, `done`, `openSession`.

Rows (`flex flex-col gap-1.5`, about 150px):

1. Title: full title (`item.title || item.label`), `line-clamp-2 font-medium`; an `<a :href="item.url">`
   (testid `ade-links-card-title`) when there is a url; click calls `openLink(item)`
   (change request: in-app host view with its browser fallback; else browser). Status `AdeChip`
   (`artifactStatusLabel`/`artifactStatusTone`) when `item.status` and origin is not `jira`.
   While `editing`: `AdeLinkEdit` replaces the title row, wrapped in a `div @keydown.escape.stop`
   so Esc cancels the edit only (second Esc closes the card).
2. Url line: `font-data text-kira-sm text-subtle` with `TruncatedText` (testid `ade-links-card-url`).
3. Meta line `text-kira-sm text-muted-foreground`: repo (`item.repo`), source word
   (`sourceLabel(item.source)`, moved from `AdeArtifactList`), origin session button
   (`AdeOriginSession`, only `mode === 'edit' || archived`; `:archived`, `@open` re-emitted).
4. Jira item: `AdeTaskIssueLine :task-id :link="`${item.label} ${item.url}`"` (title, status, PR
   count, view, gap text); its testids stay.
5. Kind (stored items, edit mode only): shadcn `ToggleGroup type="single" size="sm"`,
   `aria-label=t('space.ade.links.kind.aria')`, testid `ade-links-card-kind`; 6 `ToggleGroupItem`
   (`KINDS` order, clustered by `linkCategory`: issue | changeRequest | branch, deployment, doc,
   link; `Separator orientation="vertical"` between the 3 clusters), each icon-only,
   `aria-label` and `Tooltip` = `artifactKindLabel(k)`, `data-kind`, testid `ade-links-card-kind-item`.

6. Actions row (`flex gap-1 border-t pt-1.5`): `AdeLinkOpenExternal :url` (testid stays

### `AdeLinkAdd.vue`

shadcn `Popover` around the `+` trigger (`PopoverContent w-80 align="end"`, testid
`ade-links-add-popover`). Body: one `Input` (`size="kira"`, placeholder

`useTaskLinks.addLines` so the strip paste handler shares it.

### `useTaskLinks.ts`

```ts
export interface LinkGroup { id: LinkCategory; items: LinkItem[] }
export function useTaskLinks(
  task: MaybeRefOrGetter<Task>,
  opts: { branches?: MaybeRefOrGetter<boolean> } = {},
): {
  query;                        // useTaskArtifacts
  groups: ComputedRef<LinkGroup[]>;   // non-empty only
  gaps: ComputedRef<ArtifactGap[]>;
  error: Ref<string>;           // remove/recategorise failure
  addLines(raw: string): Promise<{ allKnown: boolean }>; // see below
  commit(item: LinkItem, text: string): Promise<void>;   // from AdeLinkGroups.commit
  remove(item: LinkItem): Promise<void>;                 // sets error
  recategorise(item: LinkItem, kind: Artifact['kind']): Promise<void>;
  openLink(item: LinkItem): void;                        // from AdeDetailsLink.open
}
```

- Wraps `useTaskArtifacts`, `useAddLink`, `useEditLink`, `useRemoveArtifact`, `useUpdateTask`,
  `useOpenChangeRequest` (TanStack Query, unchanged). `commit`, `remove`, `recategorise` move
  verbatim from `AdeLinkGroups.vue`; `openLink` from `AdeDetailsLink.vue`.
- Jira tone: `useTaskIssue(() => task.id, () => jira ? `${jira.key} ${jira.url}` : '',
  () => Boolean(task.jira))` (new optional `enabled` arg, below). Jira item gets
  `status = issue.status`, `tone = CATEGORY_TONE[issue.statusCategory] ?? 'grey'` when a title
  came back. Same query key as `AdeTaskIssueLine`, so one call.
- `addLines` runs `AdeLinkAddLine.submit`'s loop; on a failure it rethrows with the index of the
  failed line so `AdeLinkAdd` keeps the remaining lines. `AdeLinkAdd` owns `text`/`error`/`known`
  refs and calls it. Implementer may keep `submit` inside `AdeLinkAdd` and have the strip paste
  handler open the add popover and hand the text over instead; pick the smaller diff, one code path.

### Keyboard

- Tab enters the strip on the last-focused (first) pill; one tab stop. Left/Right/Home/End move
  across pills and lines (roving focus, loops). Up/Down jump to the first pill of the previous/next
  line.
- Enter: `openLink(item)` (change request: host view; else browser); `preventDefault` so the
  button click (card) does not fire. Space or click or Alt+Down: open card. Esc: close card, focus
  back on its pill (Popover default return focus).
- F2: open card with editing on (edit mode, origin not detected). Delete/Backspace: `remove(item)`
  (edit mode; stored, jira, host); focus moves to the next pill, else previous, else `+`.
- `+` with strip focused: open add popover. Ctrl/Cmd+V with a pill focused: file the pasted lines
  (edit and add modes); multi-line paste files each line, as today.

### States

- Loading: one line, 3 `Skeleton` pills; lines reserve 24px each, no layout shift.
- Error: `QueryState` inline error with Retry (as today).
- Gaps: one amber text block, one sentence per gap (no `Alert` boxes).
- Empty: "No links yet." plus "Paste a link or press +." in edit and add modes.
- Add error / already linked: one `text-kira-sm` line inside the add popover; clears on next input.

### Primitives

shadcn-vue `Popover`, `ToggleGroup`, `Collapsible`, `Tooltip`, `Input`, `Skeleton`, `Separator`;
reka-ui `RovingFocusGroup`/`RovingFocusItem` (base of shadcn `ToggleGroup`; no shadcn wrapper exists
for a free roving group); VueUse `useEventListener`, `onKeyStroke`; TanStack Query hooks above.
Command, Tabs and Select rejected: pills need no search, and tabs hide two of three categories.
