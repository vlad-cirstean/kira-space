## Decisions

1. Archive: annotated tag `archive/memory-v0.3.18` on base, not a branch. Tags pass
   `scripts/check-push-refs.sh` and `.githooks/pre-push`; name misses `v*.*.*`, so no release runs;
   survives squash merge. No hook or GitHub setting change. One line in ARCHITECTURE (app fact) under a
   short "Removed modules" note where the Memory section was.
2. `internal/memory/workerproc` moves to `internal/workerproc` (generic NDJSON child-process shell, own
   package; jsengine is its only consumer but the shell is not JS-specific). `memfmt.StripMarkup` and
   its helpers move into `scripts/docshistory/markup.go` (sole consumer; `textloss` stays
   text-diff only). `internal/memory/embed` has no other consumer: goes.
3. ONNX goes entirely: `github.com/yalue/onnxruntime_go`, tokenizer module (and any other dep only
   memory pulled; `go mod tidy` decides), `scripts/fetch-onnxruntime.sh`, darwin Taskfile
   `fetch:onnxruntime` and dylib bundling, `verify-packaging.sh` S12, `NOTICES.md` "ONNX Runtime and
   the arctic-embed-s model" section, `apps/kira-space/.gitignore` `build/onnxruntime`. Darwin bundle
   drops the ONNX Runtime dylib (about 43 MB per `docs/PACKAGING.md` ONNX paragraph; implementer quotes
   the exact figure from that paragraph in Result, no new measurement).

   (`GateVars`, `ExtractVars`, `MergeVars`, `RewriteVars`, `FinalizeVars`, `VerifyVars`, `CauseVars`,

   (only `allowed-losses.tsv` is read; confirm), i18n `llmPrompts.entry.memory*` and `llmPrompts.var.*`
   keys only removed fields used, `PromptsPane.vue` memory group. Keep `CountVars` (agentmcp),
   `MaxVars` (agentmcp), `LimitVars` (dbmcp). Settings prompt export iterates the registry, so it
   shrinks with it; no export code change.
5. Experimental pane goes: `ExperimentalPane.vue`, `experimental.ts`, `ExperimentalSettings`, the
   `experimental` settings leaf, nav entry, i18n. An empty pane is UI with no function.
   `settings-experimental.spec.ts` becomes the old-keys load spec (step 8).
